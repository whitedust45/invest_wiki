# 高分红现金流观察候选池 / High Dividend Cashflow Watchlist

> **定位**：这是“高分红现金流观察池”，不是自动买入白名单。进入本池只代表值得跟踪和方便记录，真正买入仍要看价格、股息可持续性、资产负债表、行业周期和组合仓位。

本页服务于 [[personal-hybrid-barbell-matrix]] 里的“高分红确定性生活底座”：先用候选池降低重复查询成本，再用估值和基本面过滤决定是否执行。

## 使用原则

1. **宽进严买**：下拉候选项可以完整保留，买入前仍需重新审查赔率和风险。
2. **代码优先**：A/H/B 多市场标的必须带市场前缀或交易所口径，避免把同一公司不同证券混在一起。
3. **分层观察**：白酒、银行、保险、运营商、能源等“现金流来源”不同，不应只用股息率排序。
4. **同步口径**：当前仪表盘自动同步价格主要覆盖 A 股六位代码和美股 ETF；港股、B 股暂按手工估值处理。

## 买入前检查清单

| 检查项 | 目的 |
|---|---|
| 股息来源 | 分红来自稳定经营现金流，还是一次性资产处置/周期高点利润 |
| 资产负债表 | 高分红是否以加杠杆、牺牲再投资或透支未来为代价 |
| 周期位置 | 煤炭、油气、建筑、供应链类不能只看当期股息率 |
| 估值折价 | 好公司也需要 [[margin-of-safety|安全边际]]，尤其是高分红股容易被“股息率幻觉”误导 |
| 税费与市场 | 港股、B股要单独考虑交易货币、税费、流动性和折溢价 |
| 仓位相关性 | 白酒、金融、地产链、资源股各自有同源风险，不能把“高股息”误认为天然分散 |

- 年度分红在权益分派实施公告前仍按“预案”处理，不等同于已经到账。

## 龟龟三因子审查

**[2026-07-05 via [[2026-07-05-guigu-opening-basic-methodology]]]**
本池未来买入前应接入 [[guigu-cashflow-defensive-investing-framework]] 的三因子审查。进入候选池只代表可跟踪，真正买入至少要通过下面三层：

| 因子 | 核心问题 | 未通过时的处理 |
|---|---|---|
| [[guigu-business-model-screen|商业模式]] | 是否看得懂、低重复资本开支、收真现金、有定价权、弱周期 | 不买或只观察 |
| [[look-through-return-rate|穿透回报率]] | 保守分红和注销回购是否至少提供 3%，最好 5%+ 的到手回报 | 等价格，不因“好公司”硬买 |
| [[distributable-cash-balance|可支配现金结余]] | 分红是否来自经营现金和安全现金储备，而不是贷款或一次性处置 | 降级或剔除现金流仓 |

这会把“宽进严买”具体化：下拉候选项可以宽，但真实买入必须严。尤其对高股息股，不能只看股息率，要先确认股息背后的商业模式、现金流和负债结构。

换句话说，本页的“宽进”只适用于观察池和仪表盘候选项，不代表绕过三因子审查的买入许可。

## 与静态烟蒂策略的边界

**[2026-07-05 via [[2026-07-05-static-cigar-butt-factor-asset-cushion]], [[2026-07-05-static-cigar-butt-factor-positive-cash-inflow]]]**
港股高息/特殊资产、B 股折价池里的部分标的，可能同时具备“高息现金流”和“资产折价”两种叙事，但两者不能混用。

[[static-value-cigar-butt-framework|静态价值型烟蒂投资框架]] 关注的不是“公司能不能长期持续分红”，而是当前可确认资产是否已经接近或超过市值，并且企业后续经营不会继续消耗这层资产垫。它应作为本观察池的策略对比框架，而不是高分红筛选的替代品。

| 维度 | 高分红现金流 / 龟龟框架 | 静态价值型烟蒂框架 |
|---|---|---|
| 核心锚点 | 分红、回购和 [[look-through-return-rate|穿透回报率]] | [[asset-cushion|存量资产垫]] 和清算价值 |
| 第一问题 | 股息是否来自稳定经营现金流 | 可变现资产扣除真实负债后是否覆盖市值 |
| 现金流角色 | 用 [[distributable-cash-balance|可支配现金结余]] 判断分红可持续性 | 用 [[positive-cash-inflow|正现金流入]] 判断资产垫是否继续被消耗 |
| 主要风险 | 股息率幻觉、周期高点分红、借钱分红、商业模式恶化 | 资产不可变现、隐藏负债、治理折价、便宜但长期不兑现 |
| 执行定位 | 可作为高分红现金流仓候选，过三因子后再谈核心仓位 | 默认特殊资产/小仓候选，兑现逻辑清晰后才讨论推升 |

执行分流规则：

1. 如果标的主要卖点是“稳定分红、现金流替代劳动收入”，优先走 [[guigu-cashflow-defensive-investing-framework|龟龟现金流防御型投资框架]]。
2. 如果标的主要卖点是“现金、物业、待售资产、B 股/港股折价或控股公司折价”，优先走 [[static-value-cigar-butt-framework|静态价值型烟蒂投资框架]]。
3. 如果同一标的同时具备高息和资产折价，应分别跑两套框架，并把仓位上限按更保守的一套处理：不能用股息率替代资产垫核验，也不能用账面资产替代分红可持续性核验。

## 仪表盘落地口径

- 高分红模块下拉候选项采用本页完整观察池。
- A 股代码保留六位数字，方便现有持仓估值同步逻辑识别。
- 港股统一写成 `HK:xxxxx`，B 股统一写成 `B:xxxxxx`，现阶段作为手工估值资产。
- 历史流水记忆仍优先保留：如果用户后续手工录入过同一代码，仪表盘会继续使用最近一次代码/名称配对。
