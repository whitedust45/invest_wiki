# 高分红现金流观察候选池 / High Dividend Cashflow Watchlist

> **定位**：这是“高分红现金流观察池”，不是自动买入白名单。进入本池只代表值得跟踪和方便记录，真正买入仍要看价格、股息可持续性、资产负债表、行业周期和组合仓位。

本页服务于 [[personal-hybrid-barbell-matrix]] 里的“高分红确定性生活底座”：先用候选池降低重复查询成本，再用估值和基本面过滤决定是否执行。

## 使用原则

1. **宽进严买**：下拉候选项可以完整保留，买入前仍需重新审查赔率和风险。
2. **代码优先**：A/H/B 多市场标的必须带市场前缀或交易所口径，避免把同一公司不同证券混在一起。
3. **分层观察**：白酒、银行、保险、运营商、能源等“现金流来源”不同，不应只用股息率排序。
4. **同步口径**：当前仪表盘自动同步价格主要覆盖 A 股六位代码和美股 ETF；港股、B 股暂按手工估值处理。

## 买入前检查清单

| 检查项 | 目的 |
|---|---|
| 股息来源 | 分红来自稳定经营现金流，还是一次性资产处置/周期高点利润 |
| 资产负债表 | 高分红是否以加杠杆、牺牲再投资或透支未来为代价 |
| 周期位置 | 煤炭、油气、建筑、供应链类不能只看当期股息率 |
| 估值折价 | 好公司也需要 [[margin-of-safety|安全边际]]，尤其是高分红股容易被“股息率幻觉”误导 |
| 税费与市场 | 港股、B股要单独考虑交易货币、税费、流动性和折溢价 |
| 仓位相关性 | 白酒、金融、地产链、资源股各自有同源风险，不能把“高股息”误认为天然分散 |

## 仪表盘落地口径

- 高分红模块下拉候选项采用本页完整观察池。
- A 股代码保留六位数字，方便现有持仓估值同步逻辑识别。
- 港股统一写成 `HK:xxxxx`，B 股统一写成 `B:xxxxxx`，现阶段作为手工估值资产。
- 历史流水记忆仍优先保留：如果用户后续手工录入过同一代码，仪表盘会继续使用最近一次代码/名称配对。
