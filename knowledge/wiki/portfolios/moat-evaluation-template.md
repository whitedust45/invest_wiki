# 护城河评估模板 / Moat Evaluation Template

> **定位**：这页不是回答“这家公司贵不贵”，而是回答“这家公司到底凭什么算好公司”。
>
> **核心提醒**：[[moat|护城河]] 不能只靠商业叙事判断，也必须看它有没有被财务报表长期验证出来。

这页本质上是给 [[value-investing|价值投资]] 做一层“公司质量验证模板”：不是只看故事，而是把故事和报表、现金流、[[dividend|分红]] 能力一起看。

## 为什么要把财务体现单独拎出来

很多公司在故事层看上去有壁垒，但真正值得长期跟踪的好公司，通常会在报表里反复留下痕迹：

- 毛利率长期高且稳；  
- 净利率长期高且稳；  
- [[roe|ROE]] / ROIC 长期优秀；  
- 经营现金流持续健康，甚至长期强于净利润；  
- 大量净现金或极低有息负债；  
- 即使行业波动，利润率和现金流也不容易塌。  

所以，护城河判断至少要分成两层：

1. **来源层**：这家公司为什么强？  
2. **验证层**：这种强有没有被报表长期证明？  

## 六字段母版

以后看任何一家公司，我都尽量按下面 6 个字段来写：

### 1. 护城河来源

回答：这家公司靠什么形成优势？

常见答案包括：

- 品牌 / 定价权  
- 客户网络 / 渠道控制  
- 治理 / 资产质量  
- 成本优势 / 规模效应  
- 技术 / 工艺 / 专利  
- 资质 / 牌照 / 区域垄断  
- 资产负债表优势  

### 2. 财务体现

回答：护城河有没有被报表验证出来？

我重点看两类：

#### A. 结果型指标

- 毛利率是否长期高且稳  
- 净利率是否长期高且稳  
- [[roe|ROE]] / ROIC 是否长期优秀  
- 经营现金流是否持续强劲  
- 分红能力是否真实而非勉强  

#### B. 韧性型指标

- 是否有大量净现金  
- 有息负债是否很低  
- 利息保障倍数是否充足  
- 经济下行时利润率是否依然稳  
- 是否依赖融资续命  

### 3. 验证指标

回答：以后跟踪时最应该盯哪几个数字？

例如：

- 银行：不良率、拨备覆盖率、净息差、财富管理收入  
- 白酒：毛利率、净利率、渠道价差、现金流  
- 制造业：单位成本、毛利率、现金流、资本开支效率  
- 商业地产：出租率、租金现金流、净现金 / 负债结构  

### 4. 失效信号

回答：什么情况说明护城河可能在变弱？

常见信号：

- 毛利率、净利率持续下滑  
- 负债显著抬升  
- 经营现金流长期弱于净利润  
- 价格战导致回报率下台阶  
- 核心客户、渠道或品牌势能受损  

### 5. 适合的仓位表达

回答：这种公司更适合在组合里扮演什么角色？

- 核心长期跟踪  
- 防御底仓  
- 优质但等赔率  
- 结构复杂只观察  

### 6. 一句结论

最后必须压缩成一句最短判断：

> 它到底是“真护城河公司”、
> “财务验证不足的好故事”，
> 还是“报表好看但护城河未必深”。

## 常见护城河类型母版

### 1. 品牌 / 定价权型

典型来源：品牌势能、消费者心智、渠道价盘控制、稀缺资产。  
常见财务体现：高毛利率、高净利率、现金流强、分红能力强。  
失效信号：渠道价格倒挂、毛利率持续下滑、品牌老化。  

### 2. 客户网络 / 治理 / 资产质量型

典型来源：客户基础、资金沉淀、风控能力、治理结构。  
常见财务体现：稳定 [[roe|ROE]]、较低不良率、较强拨备、利润波动较小。  
失效信号：资产质量恶化、治理失效、核心客户流失。  

### 3. 成本 / 规模 / 技术型

典型来源：单位成本优势、规模效应、工艺效率、专利与技术积累。  
常见财务体现：较高 [[roe|ROE]]、现金流强、在行业下行期利润率仍有韧性。  
失效信号：价格战、原材料大幅波动、技术代际落后。  

### 4. 区域壁垒 / 现金流模式型

典型来源：区域垄断、稳定租赁模式、商户粘性、资产位置。  
常见财务体现：净利率高、资本开支低、分红稳定、负债结构健康。  
失效信号：区域需求转弱、出租率下滑、资产负债表恶化。  

### 5. 资产负债表优势型

典型来源：大量净现金、极低有息负债、强融资能力、危机中还能主动出手。  
常见财务体现：利息负担轻、自由现金流更真实、在行业下行时更能扛波动。  
失效信号：净现金快速消耗、债务激增、分红靠借钱维持。

- [[luzhou-laojiao]]：品牌 / 定价权型；财务体现为高毛利、高净利、高 [[roe|ROE]]、高分红。  
- [[china-merchants-bank]]：客户网络 / 资产质量型；财务体现为较稳 [[roe|ROE]]、低不良率、高拨备。

### 次级例子

- [[fusen-home]]：区域壁垒 / 现金流模式型；财务体现为高净利率、较强股息、资产价值支撑。

## 最小使用方式

以后看一家公司，最少先回答这 5 个问题：

1. 它到底靠什么形成护城河？  
2. 这种护城河有没有被报表长期验证？  
3. 最关键的验证指标是哪 2-3 个？  
4. 最先坏掉的失效信号是什么？  
5. 它适合进“核心跟踪 / 防御底仓 / 等赔率 / 只观察”的哪一层？  

如果第 2 题答不清，这家公司通常还不配进入高优先级候选池。

## 龟龟商业模式六问

**[2026-07-05 via [[2026-07-05-guigu-stock-factor-business-model]]]**
龟龟投资法给高股息公司研究补了一套更偏执行的 [[guigu-business-model-screen|商业模式筛选]]。以后本模板用于现金流防守仓时，还要额外回答六个问题：

| 问题 | 要排除的风险 |
|---|---|
| 能否看懂 | 看不懂业务、产品、需求和赚钱方式时，投资会退化成跟风 |
| 是否需要重复性资本开支 | 利润长期被再投资吞掉，股息和自由现金流不稳定 |
| 赚真钱还是假钱 | 利润挂在应收账款上，可能坏账、占资或靠融资周转 |
| 竞争还是垄断 | 高度内卷行业利润难预测，弱垄断或资质壁垒更适合现金流仓 |
| 有没有定价权 | 成本上涨无法传导时，毛利率和分红会被周期压垮 |
| 周期性有多强 | 强周期利润和股息不可预测，不适合作为稳定现金流底座 |

这六问不替代护城河分析，而是把护城河落到现金流和股息稳定性上。若一家公司护城河叙事很强，但六问里连续失败，就不应进入高分红现金流仓的高优先级。
