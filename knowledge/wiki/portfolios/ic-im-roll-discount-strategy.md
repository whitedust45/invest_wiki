# IC/IM 滚贴水长期持有策略 / IC-IM Roll Discount Strategy

> **定位**：这不是纯基差套利，也不是 [[momentum|动量]] 追涨策略，而是一个以 [[value-investing|价值投资]] 为底、以 [[margin-of-safety|安全边际]] 和 [[position-sizing|仓位管理]] 为约束、通过股指期货放大长期指数收益的组合策略。
>
> **第一原则**：**绝不因杠杆失控而被迫离场。** 贴水只是增强，核心是“买得便宜 + 永远留在市场”。

## 策略核心
这套框架把 A 股股指期货的使用顺序重新排了优先级：

1. **核心收益来源**：在估值较低时持有指数，吃长期权益回报。  
2. **工具选择原因**：用期货代替融资放大敞口，避免显性借贷利息。  
3. **贴水的角色**：比较“净年化贴水”来优化合约选择，但它只是增强项，不是上杠杆的主理由。  
4. **最重要的约束**：不能爆仓，不能在大跌中被迫离场，必须优先保护“继续持有”的资格。  

合约本身的乘数、交割日和保证金基础规则见 [[stock-index-futures|股指期货]] 与 [[stock-index-futures-contract-rules]]。

## 结构设计
### 1. 底仓与弹性仓
- **IC 是底仓**：承担“长期留在市场里”的主要职责。  
- **IM 是弹性仓**：只在中证 1000 明显更低估时加一次，用来提高弹性。  
- 若后续必须主动降杠杆，**先动 IM，最后才动 IC**。  
### 2. 估值与合约的分工
- **估值决定要不要持有、敢不敢持有**。  
- **净年化贴水决定同样要持有时，哪张合约更划算**。  

它在组合层面仍然属于一种偏进攻型的 [[asset-allocation|资产配置]] / 杠杆配置决策，而不是无风险收益替代品。

> 从 [[factor-investing|因子]] 视角看，这里的“贴水”本质上就是中证宽基期货的正 [[carry|Carry]]：本策略相当于在收 carry，同时承担基差扩大的风险。

因此，[[mean-reversion|均值回归]] 和贴水收敛只用来辅助优化，不取代低估买入的主逻辑。

## 华泰 IC 指增白皮书补强

[[2022-06-22-huatai-ic-index-enhancement-whitepaper-part-1]] 和 [[2022-07-06-huatai-ic-index-enhancement-whitepaper-part-2]] 给这套策略补了一个外部参照系：

- **贴水是风险补偿，不是无风险套利**：白皮书把 IC 贴水理解为对冲需求、对冲工具约束和中证 500 beta 风险共同作用的结果。  
- **展期要服务于连续持有**：到期收敛来自现金交割制度，但交割日最后两小时均价口径会让实际收盘价与指数收盘价存在差异，因此长期滚动更重视交易连续性。  
- **近远月选择是执行增强**：根据年化基差在近远月之间切换，本质上是在利用基差均值回归；但这只优化持有成本，不改变估值和仓位安全的优先级。  
- **资产阶段要匹配工具**：白皮书认为 IC 吃贴水更适合已有中上规模资产、能长期配置一部分资金在 IC 上的投资者；资产较小时，指数定投/ETF 更自然。  
- **跨品种迁移要谨慎**：商品期货和其他市场股指期货也可能有 carry 机会，但底层前提不同，不能把“有贴水”直接等同于“适合长期多头”。  

## 风险原则
### 1. 不做价格止损，做“杠杆止损”
这套策略不依赖“跌破某点位砍仓”，而是依赖以下三条纪律：

- 控制总名义敞口相对总资本的倍数。  
- 把期货账户权益维持在占用保证金的安全倍数之上。  
- 当风险度被拉高时，优先补充资本；若不想补，先减 IM。  

### 2. 关键监控指标
- **总杠杆** = 总名义本金 / 总可动用资本  
- **保证金风险度** = 占用保证金 / 期货账户权益  
- **回撤** = 当前总资产相对阶段高点的跌幅，见 [[drawdown|回撤]]  
执行上更重要的是第二项：

- 风险度 **< 50%**：舒服区  
- 风险度 **50% - 55%**：可观察  
- 风险度 **55% - 60%**：建议小额补资  
- 风险度 **60% - 70%**：进入防守区  
- 风险度 **> 70%**：若不愿继续补资，应优先缩减 IM  

## 前瞻闸门与缓冲带（观点，待实盘验证）
本节把跨资产 [[cross-asset-carry-momentum|carry-momentum 组合]] 里的 **vol-targeting** 与 **缓冲带** 两条思想，离散化迁移到本策略。机构版是连续、自动、看波动；个人版应保持离散、手动、低频，只抽取两条原则：**①风险指标抬升就降敞口；②同样估值下高波动少下注。**

### 1. 前瞻闸门（补"事后信号"的不足）
现有风险度是**事后**指标——跌完才升高。波动率有聚集性，可作**前瞻**信号：

- 当中证 500 / 1000 近 20 日波动率冲到**过去一年高分位**时，即使风险度还没到 55%，也**暂停加 IM**，并提前预留补资。  
- 等于给"加仓"动作加一道波动率否决权：估值便宜不等于此刻该加。  

### 2. 波动决定加仓尺寸（不只看 PB）
保留"PB 决定要不要加"，新增"**波动决定加多激进**"：

- 极低估但波动也极高时，放慢节奏（推迟 / 分批），而不是无脑上满 1 手 IM。  
- 对应连续版 `敞口 ∝ 1/波动` 的离散表达。  

### 3. 缓冲带迟滞阈值（降低临界点反复操作）
把现有单阈值改成**进出不同线**（hysteresis），避免压线反复动、反复交手续费：

| 现有单阈值 | 改为缓冲带迟滞 |
|---|---|
| 风险度 > 55% 补资 | 升破 **57%** 才补资，回落 **52%** 以下才解除 |
| 风险度 > 70% 减 IM | 升破 **70%** 减 IM，回到 **62%** 以下才考虑加回 |
| PB ≤ 20% 加 IM | 加完后 PB 回升 **25%** 以上才算退出加仓区 |

> 缓冲带本质是"只有偏离超过带宽才动，且只调到带边缘"。它牺牲一点跟踪精度换取更低换手，正契合本策略"长期纪律卡而非一次性押注"的定位。

## 2026-05-15 示例参数（非实时数据）
以下数字全部是为了建立压力测试框架的**示例假设**，不是实时市场报价：

- IC 点位：5600  
- IM 点位：5900  
- 合约乘数：200  
- 保证金率：16%  
- 初始总资金：100 万  
- 初始期货账户：55 万  
- 初始备用池：45 万  
对应名义本金：
- 1 手 IC ≈ 112 万  
- 1 手 IM ≈ 118 万  
- 1 手 IC + 1 手 IM ≈ 230 万  

## 初始建仓方案
### 未建仓时的观察面板
在你**还没建仓**时，不应该急着用“加 IM 要补多少钱”的问题来反推交易，而应先做一个更简单的判断：

1. 现在是不是**等待区**？  
2. 现在是不是**观察区**？  
3. 现在是否进入第一手 **IC 底仓执行区**？  
4. 现在是否允许把 **IM** 纳入未来单次加仓候选？  
一个可执行的默认版本是：
- **PB 百分位 > 40%**：等待区，不启动策略。  
- **30% < IC PB 百分位 ≤ 40%**：观察区，持续跟踪，但不急着开第一手 IC。  
- **IC PB 百分位 ≤ 30%**：IC 进入底仓执行区。  
- **IM PB 百分位 ≤ 20%**：IM 进入单次加仓候选区。  
- **IM PB 百分位 ≤ 10%**：IM 进入极低估优先区。  
这意味着：
- **IC 决定是否启动策略**。  
- **IM 决定启动后是否值得准备弹性仓**。  
- 如果 IC 和 IM 都还在高 PB 百分位，哪怕你很想“先拿一点底仓”，也更符合本策略精神的动作仍然是**空仓等待**。  
### 推荐起步
对“100 万起步、绝不爆仓”这件事，推荐的第一步不是 1 手 IC + 1 手 IM，而是：

- **先只持有 1 手 IC**  
- 期货账户放 **55 万**  
- 备用池留 **45 万**  
这样做的原因：
- 初始总杠杆约 **1.12 倍**，明显低于危险区。  
- 即使指数先跌 20% - 25%，风险度仍在可承受范围内。  
- 给后续“极低估时只加 IM”留出资金与心理空间。  

## 初始 1 手 IC 的压力测试
在上面的示例参数下，若只持有 1 手 IC：

| IC 跌幅 | 期货账户权益 | 占用保证金 | 风险度 | 补到 55% 需补 |
|---|---:|---:|---:|---:|
| 0% | 55.0 万 | 17.92 万 | 32.6% | 0 |
| -10% | 43.8 万 | 16.13 万 | 36.8% | 0 |
| -15% | 38.2 万 | 15.23 万 | 39.9% | 0 |
| -20% | 32.6 万 | 14.34 万 | 44.0% | 0 |
| -25% | 27.0 万 | 13.44 万 | 49.8% | 0 |
| -30% | 21.4 万 | 12.54 万 | 58.6% | 1.41 万 |
| -35% | 15.8 万 | 11.65 万 | 73.7% | 5.38 万 |

这说明：**只做 1 手 IC 的起步结构很耐跌**，与 [[position-sizing|仓位管理]] 和 [[drawdown|回撤]] 约束是相容的。

## 低位只加 IM 的规则
### 加仓触发条件
满足以下条件时，才考虑加 1 手 IM：

1. 中证 1000 的 PB 百分位进入你定义的极低区。  
2. 你仍然坚持“长期持有指数”的主判断。  
3. 有额外新增资金，不靠原有 100 万硬挤仓位。  
4. 加完后即使市场再跌，也不会立刻把风险度推到失控区。  
一个可执行的简化版本是：
- **PB 百分位 > 20%**：默认不新增 IM，只持有 IC 底仓。  
- **PB 百分位 ≤ 20%**：进入“可以测算单次 IM 加仓”的区域。  
- **PB 百分位 ≤ 10%**：若你仍有新增资金且风险度安全，可以把这视作最优先考虑的 IM 加仓窗口。  
这里的 PB 百分位只负责回答“估值够不够便宜，值得不开新杠杆去加 IM”，而不取代资金安全测算。
### 每次需要比 100 万额外补进来的金额
在“100 万起步、先持有 1 手 IC”的前提下，若你准备在不同低位加 1 手 IM，为了尽量满足“加完后再跌 20% 也不容易爆仓”，建议额外补充如下资金：

| 相对初始建仓点位已跌 | 建议额外补充资金 |
|---|---:|
| 10% | 35.5 万 |
| 15% | 37.0 万 |
| 20% | 38.0 万 |
| 25% | 39.0 万 |

这些金额不是“最低能开出 IM 的钱”，而是按**保守生存标准**算出来的安全垫。
## 加完 1 手 IM 之后的再跌补资规则
若已经按上表补资并加了 1 手 IM，则后续继续下跌时，可以用下面这张“二阶段补资梯子”做近似执行：

| 加完 IM 后再跌 | 为把风险度拉回 55% 以下，通常还需再补 |
|---|---:|
| 10% | 0 |
| 15% | 2.5 - 3.0 万 |
| 20% | 9.0 - 10.5 万 |
| 25% | 14.5 - 17.5 万 |
执行顺序建议：
1. **先补资**，争取把风险度拉回 55% 以下。  
2. 若不愿继续补资，则**优先减 IM**。  
3. IC 只在极端情况下才动，因为它承担底仓角色。  
## 合约选择：默认当季，但要比较净年化贴水
你的主逻辑是长期持有，因此合约选择的优先顺序是：

1. 默认优先做**当季合约**，降低频繁换月成本。  
2. 到移仓窗口时比较**净年化贴水**。  
3. 若其他候选合约显著更优，再偏离“当季优先”。  
可用简化公式：
```text
净年化贴水 ≈ (现货指数 - 期货价格) / 现货指数 × 365 / 剩余天数
           - 双边手续费 - 预估滑点
```
这里的作用只是优化执行价格，不改变“便宜时长期持有”的主命题。
## 可执行纪律卡片
### 做什么
- 用 [[margin-of-safety|安全边际]] 理解估值区间，而不是追求抄到最低点。  
- 用 [[position-sizing|仓位管理]] 约束杠杆，而不是只看方向判断。  
- 用 [[rebalance|再平衡]] / 降杠杆思路处理风险抬升，而不是靠主观扛单。  
### 不做什么
- 不用 100 万初始资金直接开 1 手 IC + 1 手 IM。  
- 不在没有新增资金的情况下硬挤出 IM。  
- 不把“贴水深”误当成“可以无脑上杠杆”。  
- 不在加了第一手 IM 后继续轻易加第二手 IM。

## 结语
这套策略真正的目标不是“收益最大化”，而是：

> **在指数足够便宜时拿到足够多的敞口，同时无论市场怎么波动，都保住继续留在场内的资格。**

它更像一张长期执行的纪律卡，而不是一次性押注。

若把它放到更大的个人总组合里看，可结合 [[personal-hybrid-barbell-matrix]] 一起理解：在那个框架中，IC / IM 承担的是“结构收益仓”，而不是整个账户的全部风险暴露。
