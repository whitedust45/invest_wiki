# 个人混合杠铃投资矩阵 / Personal Hybrid Barbell Matrix

> **定位**：这不是纯教科书版 [[barbell-strategy|杠铃策略]]，而是我把 [[asset-allocation|资产配置]]、[[position-sizing|仓位管理]]、A 股滚贴水经验与美股尾部保险结合后的个人执行框架。

## 一句话 thesis

我的最终目标不是“找到收益最高的单一资产”，而是构造一个：

> **平时能拿得住、极端时不致命、真正的大机会来时又能赚到非对称收益的组合系统。**

这意味着我不再追求“所有仓位都统一逻辑”，而是接受不同仓位承担不同职责。

## 当前版本的资金结构

> **[2026-06-23 补充]** 下表是资金规模成型后的理想结构，不应在资金不足阶段机械等比例缩小。小资金阶段应先满足生活现金、现金流底仓与右尾仓，再逐步引入 IC / IM 和 SPY put。

| 模块 | 金额 | 职责 |
|---|---:|---|
| 高股息 / 红利低波 | 200 万 | 现金流防守仓 |
| IC / IM 滚贴水 | ~~200 万~~ **198 万** | 结构收益仓 |

| QQQ | 70 万 | 右尾成长仓 |
| SPY 深度虚值 put | ~~10 万~~ **12 万** / 年 | 左尾保险仓 |

**[2026-06-01 更正]** SPY put 年度预算由 10 万上调至 12 万（占总组合 2%），差额 2 万从 IC / IM 模块挤出。依据：2026 年初对 600 万版回测复盘显示，10 万（1.7%）保险费在更极端的历史样本里覆盖度偏低，提到 12 万后保险有效性显著改善，且对 IC / IM 结构收益的稀释可忽略。详见 frontmatter 中 2026-06-01 personal 来源条目。

这套结构不是简单的“分散买五样东西”，而是五个功能模块并列：

- 高股息负责平时持有体验与现金流  
- IC / IM 负责结构性收益  
- 国债逆回购负责在危机中保留行动能力  
- QQQ 负责暴露在科技成长的右尾弹性里  
- [[rebalance|再平衡]] 负责在各模块偏离职责时，把组合拉回原本的风险结构  
- SPY put 负责在黑天鹅里提供左尾保护  

## 为什么它不是纯塔勒布，但仍然有塔勒布内核

如果按最原教旨的 [[barbell-strategy|杠铃策略]]，左侧通常会更大，右侧通常更纯粹，整个组合会更极端。

我的版本之所以不是纯塔勒布，有两个原因：

1. 我希望组合不仅能“危机里活下来”，也能在常态年份有较好的持有体验。  
2. 我已经有对 A 股 IC / IM 滚贴水的长期理解，所以不会把所有风险暴露都放在单一市场。  

但它仍然保留了塔勒布内核，因为：

- 我承认自己无法稳定预测拐点。  
- 我愿意用国债逆回购保留左侧生存能力。  
- 我愿意把 SPY put 当作保险费，而不是赚钱工具。  
- 我接受 [[drawdown|回撤]] 控制和生存性优先于表面收益最大化。  

## 我对每个模块的真正理解

### 1. 高股息 / 红利低波

这一块不是“绝对安全”，而是权益里的偏防守资产。它的意义不是让我躲过所有下跌，而是降低纯成长仓带来的持有难度。

### 2. IC / IM 滚贴水

这一块不是固收替代，也不是无风险套利，而是一种带有杠杆和执行纪律要求的专业策略。它的本质更接近 [[ic-im-roll-discount-strategy]] 里强调的：**长期便宜持有指数 + 用贴水优化执行 + 严控风险度。**

### 3. 国债逆回购

这是我版本里最关键的一环。没有这部分，整个系统就会从“杠铃”退化成“多策略进攻组合”。它承担的是安全垫、补保证金、等待机会和危机时再出手的职责。

### 4. QQQ

QQQ 在这里不是严格意义上的 [[convexity|凸性]] 资产，而是右尾高弹性资产。它承担的是：在美国科技继续走强的长期进程里，为整个组合提供向上的非对称收益来源。

### 5. SPY 深度虚值 put

这部分不能按“平时赚不赚钱”来评估，而要按“出大事时有没有用”来评估。它是我主动购买的灾难保险，是组合里最不应该被短期盈亏打断的部分。

## 这套矩阵最重要的优先级排序

我的优先级不是：

1. 先赚最多  
2. 再考虑怎么防守  

而是：

1. **先活下来**：确保安全垫在、保证金可控、不会因为一次错误退出市场。  
2. **再保留右侧弹性**：让 QQQ 和 IC / IM 在常态与景气阶段提供收益。  
3. **最后才谈预测与择时**：把对“市场会不会马上崩”的执念降到最低。  

这本质上是一种比 [[kelly-criterion|凯利公式]] 更上层的结构思路：先定义总暴露结构，再讨论局部仓位优化。

## 这套框架的自我约束

为了不让这套矩阵在执行中变形，我给自己设几个硬约束：

1. **IC / IM 先有规则再有仓位**，不能靠情绪临场拍脑袋。  
2. **SPY put 要预算化续买**，不能因为连续亏几年就停保。  
3. **大涨后的利润要回流到安全端**，而不是持续推高风险暴露。  
4. **任何时候都不把高股息误当成无风险资产**。

## 哪些情况会让我修正这个框架

如果未来出现以下变化，我会考虑改版：

- 我对 IC / IM 的执行边界发生变化，无法继续稳定跟踪与风控。  
- 我对 QQQ 的长期右尾逻辑失去信心，例如科技长期成长主线被系统性破坏。  
- SPY put 的长期保险成本显著上升，导致性价比持续下降。  
- 我的总资金规模、现金流需求或风险承受能力发生明显变化。  

这意味着，这个框架不是“永远不变的真理”，而是我在当前资金量、认知与执行能力下的最优个人版本。

## 当前结论

> **我的最终投资矩阵，不是押一个方向，而是把钱分配给不同职责：让安全端负责生存，让结构仓负责增厚，让成长仓负责右尾，让保险仓负责左尾。**

这就是我当前版本的个人混合杠铃框架。
