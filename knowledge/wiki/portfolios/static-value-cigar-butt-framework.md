# 静态价值型烟蒂投资框架

> **定位**：这是一个偏格雷厄姆式的 [[cigar-butt-investing|烟蒂投资]] / [[value-investing|价值投资]] 子框架，用于识别“当前资产价值明显高于市值、且不会继续烧掉资产垫”的静态低估机会。它不替代 [[guigu-cashflow-defensive-investing-framework|龟龟现金流防御型投资框架]]，而是补充“特殊资产 / 烟蒂 / 清算价值”这一类机会。

## 一句话框架

静态价值型烟蒂的核心不是“公司多好”，而是：

> 当前能确认的可变现资产已经接近或超过市值，并且公司后续经营不会把这层资产垫继续消耗掉，最好还存在明确的资产兑现路径。

这里的 [[intrinsic-value|内在价值]] 更接近资产负债表下限，而不是未来成长折现。

## 三个要义

截图素材把静态价值型烟蒂拆为三要义：

1. [[asset-cushion|存量资产垫]]：确保公司当前静态时间截面的可变现资产贴近或大于市值。
2. [[positive-cash-inflow|正现金流入]]：确保公司后续营运不需要消耗存量可变现资产，甚至能产生正自由现金流。
3. 资产兑现逻辑：公司有明确事件驱动或长期稳定派息路径，能逐步兑现高于市值的价值。

当前已摄入因子一和因子二；因子三“资产兑现逻辑”只在总览截图中出现，尚缺单独素材，暂不单独建概念页。

## 第一关：存量资产垫

先看资产负债表，而不是先看利润表。关键是用可变现资产扣除真实负债，判断剩余价值是否大于市值。

素材给出的入门天梯：

| 等级 | 粗略口径 | 解释 |
|---|---|---|
| T0 | 现金等价物 - 总负债 > 总市值 | 最强资产垫 |
| T1 | 现金等价物 - 有息负债 > 总市值 | 现金覆盖金融负债后仍高于市值 |
| T2 | 流动资产 - 总负债 > 总市值 | 依赖应收、存货、待售资产等折价判断 |
| 传统定义 | 流动资产 - 有息负债 > 总市值 | 更宽，误判风险更高 |

这不是机械公式。真正要判断的是：

- 现金、短期理财、定期存款是否真实可动用；
- 应收、存货、固定资产、投资物业、待售资产需要打几折；
- 有息负债、租赁负债、经营性负债、表外义务哪些必须真实扣除；
- 控股结构、少数股东权益和受限资产是否会削弱股东可得价值。

## 第二关：正现金流入

通过资产垫后，还要确认企业不会继续烧掉这层资产。这里的“正现金流入”不是净利润，而是现金意义上的净流入。

可用拆解：

```text
正现金流入
= 经营性现金流净流入
- 必要资本开支
- 财务费用 / 租赁负债成本
+ 较确定的资本性收入
```

不同企业科目不同，核心不是套公式，而是确认：

- 公司能否不靠融资维持经营；
- 现金流是否长期接近或好于净利润；
- 必要资本开支是否低；
- 资产处置收入是否可重复或能明确兑现资产垫；
- 如果现金流很弱，是否至少不持续侵蚀资产垫。

## 第三关：资产兑现逻辑（待补完整素材）

烟蒂股最大风险是“便宜但永远不兑现”。所以第三关必须回答：资产垫如何变成股东回报？

可观察方向包括：

- 分红或特别分红；
- 注销型回购；
- 资产出售、清算、私有化、并购重组；
- 经营现金流持续积累现金；
- 明确的事件驱动，如物业出售、投资项目退出、控股公司折价收敛。

由于用户当前只提供了因子一和因子二截图，本页只记录第三关方向，不展开成完整规则。后续拿到“资产兑现逻辑”素材后再补成单独来源页和概念页。

## 与龟龟现金流框架的边界

[[guigu-cashflow-defensive-investing-framework|龟龟现金流框架]] 的目标是打造能替代劳动收入的高股息现金流仓，要求商业模式清晰、穿透回报率足够、[[distributable-cash-balance|可支配现金结余]] 支撑分红。

静态价值型烟蒂框架的目标不同：它寻找的是资产负债表上的错价。它可以接受公司不是长期好生意，但不能接受资产垫被持续消耗、负债不可理解或兑现路径完全缺失。

简化区分：

| 问题 | 龟龟现金流框架 | 静态价值型烟蒂框架 |
|---|---|---|
| 主要锚点 | 分红 / 回购穿透回报 | 资产垫 / 清算价值 |
| 核心风险 | 假分红、假现金流、商业模式恶化 | 资产不可变现、负债低估、价值不兑现 |
| 持有目标 | 稳定现金流替代劳动收入 | 等待折价收敛或资产兑现 |
| 适合仓位 | 可成为现金流仓核心候选 | 默认小仓、事件确认后再讨论推升 |

## 初步执行纪律

- 未通过存量资产垫：直接不看。
- 通过资产垫但现金流为负：谨慎，通常只观察。
- 资产垫强、现金流不烧钱、兑现路径明确：可进入小仓/特殊资产候选。
- 治理风险、受限资产、负债不透明、控股结构复杂时，必须降低仓位上限。
- 不把低 PB、低 PE、账面现金高直接等同于 [[margin-of-safety|安全边际]]。

## 当前结论

静态价值型烟蒂框架最适合补充我现有体系中的“特殊资产机会”判断：它不追求长期伟大公司，而追求当前资产价值与市场价格之间的明显错配，并要求这层错配不会被后续经营消耗掉。
