# 尾盘绿转红超短动量系统

## 定位

本页记录一套个人 A 股隔夜超短 [[momentum|动量]] 系统草案：在强概念板块中，寻找尾盘仍保持强势、且砖型图指标由绿转红的个股，试图捕捉次日冲高与后续短线趋势延续。

这是一套交易执行框架，不是投资建议；当前状态为 `draft`，原因是尚未完成回测、实盘样本统计和滑点/隔夜低开损失记录。

## 指标底层逻辑

砖型图指标的核心变量来自最近 4 根 K 线的高低区间位置：

```text
VAR3A = (CLOSE - LLV(LOW,4)) / (HHV(HIGH,4) - LLV(LOW,4)) * 100
```

它衡量当前收盘价在最近 4 根 K 线高低区间中的相对位置：

- 收盘越靠近最近 4 根高点，短线位置越强。
- 收盘越靠近最近 4 根低点，短线位置越弱。
- 经过多次 `SMA` 平滑和阈值过滤后，形成 `砖型图`。

在交易解释上：

- `砖型图_t > 砖型图_{t-1}` 画红柱，表示短线动量增强。
- `砖型图_t < 砖型图_{t-1}` 画绿柱，表示短线动量减弱。
- 该指标只看价格位置，不包含成交量、板块强度、盘口承接或基本面信息，因此必须叠加环境和标的过滤。

## 核心交易假设

本策略押注的不是单个技术指标本身，而是三层共振：

1. 市场当下存在可交易的热门题材或强概念板块。
2. 个股属于该强势板块，且分时承接和尾盘状态仍然强。
3. 砖型图在尾盘从减弱转为增强，提示短线动量可能重新启动。

因此，信号的完整含义是：**热门板块里，尾盘仍然保持强势、且短线动量刚从下压转为上行的个股**。

## 入场规则

尾盘确认后买入，避免盘中红绿反复造成假信号。

已确认的入场条件：

1. 当天为红柱，即 `砖型图_t > 砖型图_{t-1}`。
2. 前一交易日为绿柱，即 `砖型图_{t-1} < 砖型图_{t-2}`。
3. 今日红柱长度大于昨日绿柱长度的四分之三。
4. 执行时间为尾盘，而不是盘中首次转红。

公式化表达：

```text
今日红柱长度 = 砖型图_t - 砖型图_{t-1}
昨日绿柱长度 = 砖型图_{t-2} - 砖型图_{t-1}

入场强度条件：
今日红柱长度 > 昨日绿柱长度 * 3 / 4
```

## 板块过滤

只在当日涨幅最大或涨幅前列的强概念板块中寻找候选，不做全市场无差别信号。

优先参与的板块状态：

- 概念板块当日涨幅排名靠前。
- 板块内多股共振，不是单只龙头硬拉。
- 板块成交额放大，有真实资金参与。
- 板块指数尾盘不明显回落，最好收在日内高位附近。
- 不是连续暴涨后的第三、第四天尾盘高潮。

## 个股过滤

在强板块中，优先选择核心跟涨股，而不是无差别追高。

优先选择：

- 成交额靠前，流动性足够。
- 当天涨幅靠前，强于板块平均。
- 全天分时承接强，尾盘仍在分时均线上方。
- 属于板块主线，而不是边缘蹭概念。

回避对象：

- 一字板、秒板等无法正常买入的龙头。
- 尾盘突然脉冲拉升，但全天没有承接的个股。
- 已经连续缩量加速后的高位票。
- 尾盘明显跳水或长上影的票。

## 出场规则

已确认的出场框架：

| 场景 | 动作 |
|---|---|
| 次日盘中触及买入价 +3% | 卖出 50% |
| 触发 +3% 后 | 剩余 50% 的保护位抬到买入价 |
| 后半仓继续持有期间 | 尾盘砖型图转绿时卖出 |
| 买入后跌破 -3% | 硬止损，退出 |

后半仓的退出采用同一指标逻辑：入场看尾盘绿转红，退出看尾盘转绿。这样系统内部较一致，避免把短线动量单临场改造成中线持仓。

待确认规则：

- 若次日没有触及 `+3%`，是否必须在次日尾盘退出或减仓。
- `-3%` 止损遇到隔夜低开时，按开盘价、跌破价还是尾盘执行。

## 仓位与分散

已确认的仓位规则：

| 项目 | 规则 |
|---|---|
| 单票仓位 | 33% |
| 同时持仓上限 | 最多 3 只 |
| 总仓位上限 | 不超过 99% |
| 同一主线限制 | 最多 2 只来自同一主线 |
| 第 3 只要求 | 必须来自另一条强势线 |
| 板块不足时 | 如果只有一个板块强，只买 1-2 只，不为了满仓凑票 |

按 `33%` 单票仓位和 `-3%` 止损计算，单票正常止损约损失账户 `0.99%`。如果 3 只同时触发正常止损，理论账户损失约 `3%`。

但由于该策略是尾盘买入、隔夜持仓，真正风险不是单票 `-3%`，而是同源题材次日集体低开。若 3 只高度相关，且次日平均低开 `-5%` 至 `-8%`，账户层面的损失会显著高于正常止损模型。

因此，[[diversification|分散]]规则的意义不是降低进攻性，而是避免 3 个头寸都押在同一个题材隔夜风险上。

## 不开仓条件

本策略不用机械亏损次数熔断，而使用市场状态过滤。状态过滤是核心规则，不是附属规则。

不开仓条件：

1. 当天指数明显走弱，不开新仓。
2. 当天最强概念板块尾盘回落明显，不开新仓。
3. 炸板率高、强势股亏钱效应明显，不开新仓。
4. 已持有 3 只后，不再新增。
5. 没有符合板块、个股和指标共振的票，不开仓。

这套规则的目的，是避免在主线退潮、强势股补跌或一日游题材尾盘高潮时继续机械开仓。

## 风险与失效信号

- **隔夜跳空风险**：A 股 T+1 下，尾盘买入后无法当日卖出；次日若低开，`-3%` 可能不是可执行的最终损失。
- **同源风险**：若 3 只股票都来自同一题材，表面分散并不能降低题材退潮风险。
- **假强势风险**：当天涨幅最大的概念板块可能是真主线，也可能是一日游消息刺激。
- **指标短周期噪音**：砖型图底层只看最近 4 根 K 线价格位置，容易在震荡中反复转红转绿。
- **期望值未验证**：`+3%` 半仓止盈能提高兑现率，但最终是否正期望，取决于触发率、止损率、后半仓右尾收益和隔夜低开损失。

## 候选评分模型

2026-07-11 确认的基础分合计 100 分：

| 因子 | 分值 | 解释 |
|---|---:|---|
| 砖型强度 | 28 | 绿转红后的启动强度，保持最高权重 |
| 黄白趋势 | 17 | 阶段趋势仍然成立的确认 |
| 前日 KDJ J 值 | 15 | 前一日短期调整是否充分 |
| 低 J 十字星 | 5 | 调整末端形态的固定跃升确认 |
| 板块领先度 | 12 | 当日前五概念板块中的相对位置 |
| 个股相对强度 | 10 | 个股相对所属板块的强弱 |
| 量能与流动性 | 13 | 资金参与和尾盘可成交性 |

黄白趋势不再使用阶梯分，改由白线相对黄线距离、白线斜率、黄线斜率和收盘相对黄线距离四项线性评分组成。前日 J 值以 12 为连续曲线的斜率分水岭：J 从 0 上升至 12 时由 15 分缓慢降至 12 分，J 从 12 上升至 30 时由 12 分较快降至 0 分。J=12 两侧连续，不发生突然跳分。

前日实体比例不超过 1.5% 且前日 J<12 时，十字星项固定加 5 分；J>=12 时十字星不单独加分。涨停无法买入、未收复放量阴线和关键数据缺失仍作为硬过滤归零，其他追高风险继续独立扣分。

砖型强度以“今日红柱长度 / 昨日绿柱长度”计算。严格 Python 信号要求该比值大于 `0.75`；评分从 `0.75` 的 0 分连续线性上升，到 `2.0` 时取得 28 分满分，避免刚过入场门槛就获得过高评分。

## 待验证

后续应通过回测或实盘日志至少记录：

- 信号出现频率。
- 次日触及 `+3%` 的比例。
- 未触及 `+3%` 时的平均结果。
- 硬止损触发率和实际滑点。
- 隔夜低开超过 `-3%` 的频率。
- 后半仓等待尾盘转绿的平均收益和最大回吐。
- 不开仓条件是否能有效过滤退潮日。
- `33% * 3` 最大隔夜敞口对账户 [[drawdown|回撤]] 的真实影响。

## 原始砖型图公式

2026-07-10，用户提供了通达信/同花顺原始公式：

```text
VAR1A:=(HHV(HIGH,4)-CLOSE)/(HHV(HIGH,4)-LLV(LOW,4))*100-90;
VAR2A:=SMA(VAR1A,4,1)+100;
VAR3A:=(CLOSE-LLV(LOW,4))/(HHV(HIGH,4)-LLV(LOW,4))*100;
VAR4A:=SMA(VAR3A,6,1);
VAR5A:=SMA(VAR4A,6,1)+100;
VAR6A:=VAR5A-VAR2A;
砖型图:=IF(VAR6A>4,VAR6A-4,0),COLORRED;
STICKLINE(REF(砖型图,1)<砖型图,砖型图,REF(砖型图,1),3,0),COLORRED;
STICKLINE(REF(砖型图,1)>砖型图,砖型图,REF(砖型图,1),3,0),COLOR00FF00;
红持绿空:=0,COLORGREEN;
AA:=(REF(砖型图,1)<砖型图);
BB:=REF(砖型图,1)>砖型图;
CC:=REF(AA,1)=0 &&(AA=1);
XG:=CC>0;
```

通达信原生模式默认调用客户端中名称为 `ZHUAN` 的已保存选股公式，并传入参数 `14,28,57,114,3,21`；不替换其正文。原始 `XG` 只判断当前转红且前一日不是转红，并不包含严格绿柱和红柱长度 `3/4` 条件；Python 模式按本系统已确认的严格规则独立计算：今日砖型图增加、昨日砖型图减少，且今日红柱长度大于昨日绿柱长度的四分之三。两种结果的差异会被保留用于 Windows 实机核对。

## 数据接口执行口径

筛选脚本可主动运行，也可由 Windows 任务计划在交易日尾盘运行。它从通达信概念板块缓存获取概念板块，回退时使用 `8805-8809` 前缀，计算当日涨跌幅并取涨幅前五概念板块，随后通过板块成分接口获取股票；不扫描全 A 股，也不依赖概念代码连续性。原生引擎默认调用 `ZHUAN` 和参数 `14,28,57,114,3,21`，Python 引擎使用不复权日线重算砖型图。若最新 K 线不是当前交易日，脚本不产生候选。

实盘实现：`modules/short_term/strategies/brick.py`。

历史评分回测：`modules/short_term/backtest_brick.py`。回测可选择起止日期，逐日回放原生 `ZHUAN` 与 Python 严格公式的并集，只评价全局正分 Top 5，并重点汇总 Top 3 的后续 1、2、3、5 日表现。其目的仅是验证评分排序，不模拟完整资金账户和退出交易。

回测使用历史板块指数和历史个股 OHLCVA，但板块成员来自运行回测时的当前成分，因此存在前视偏差；信号日收盘价仅作为尾盘买入近似值。结果应优先用于最近 3 至 6 个月的参数校准，不能视为精确成交收益。

## 与知识库的关系

- 本策略是 [[momentum|动量]] 在 A 股超短交易中的个人化执行版本。
- `+3%` 半仓止盈、`-3%` 硬止损和后半仓转绿退出，需要持续用 [[risk-reward|风险收益比]] 检查期望值。
- 单票 `33%` 和最多 3 只的安排，必须放在 [[position-sizing|仓位管理]] 与 [[drawdown|回撤]] 框架中评估。
- 最多 2 只同一主线、第 3 只必须来自另一条强势线，是 [[diversification|分散化]] 在超短题材交易中的具体约束。
- 若未来该策略进入总组合，应再回到 [[personal-position-sizing-framework]] 检查是否与其他仓位形成同源风险。

## 当前结论

**观点**：这套系统的优势在于把“热门板块、强势个股、尾盘动量转强、半仓兑现、尾仓跟随、状态过滤”接成了一个闭环。它的主要风险在于高隔夜敞口和题材退潮时的相关性放大。是否值得实盘放大，取决于后续样本能否证明 `+3%` 触发率、后半仓右尾收益和状态过滤足以覆盖隔夜跳空与连续假信号损失。
