# 沃伦·巴菲特 / Warren Buffett

## 人物定位

[[warren-buffett|沃伦·巴菲特]] 是 [[berkshire-hathaway]] 的长期核心掌舵者，也是这套知识库当前最重要的方法论来源之一。从这封 2025 年股东信看，他最核心的特征并不只是“选股能力”，而是把 [[capital-allocation|资本配置]]、长期再投资、诚实披露与快速纠错结合成一套持续可执行的管理框架。这也是 [[value-investing|价值投资]] 在巴菲特这里不断被升级为“理解商业模式 + 管理资本 + 约束错误”的原因。

## 在这封股东信中体现出的风格

- **坦诚披露**：把“错误”放在信的开头，强调管理层不应回避判断失误。  
- **配置优先**：更关心资本最终流向哪里，而不是短期市场情绪。  
- **长期主义**：持续强调企业股权优于长期持有现金与固定收益资产。  
- **股东对齐**：倾向把股东沟通当成受托责任，而不是公关动作。  

## 当前可提炼的认知

**[2025-02-22 via [[2026-05-14-buffett-2025-shareholder-letter]]]**  
巴菲特在 94 岁时仍明确要求伯克希尔的管理文化保持两点：一是对股东说真话，二是不要把错误拖成更大的错误。这意味着他的方法论不仅是“买什么”，更是“如何治理资本、如何面对错误、如何让复利持续发生”。这也正是 [[buffett-2025-shareholder-letter-framework]] 的底层来源。

## 对知识库的作用

- 作为人物入口，连接 [[berkshire-hathaway]] 与方法论页面。  
- 作为后续摄入巴菲特历年股东信、访谈、演讲时的统一锚点。  
- 作为 [[overview]] 中“长期主义 + 诚实披露 + 纠错机制”路线的代表人物。  

## 2020-2024 风格补充

- **[2023-03-01 via [[2026-05-15-buffett-2023-shareholder-letter]]]** 巴菲特明确说“我们不是选股高手，我们是选择商业模式的人”，这使他的核心能力从“选股”更准确地转向了“理解商业模式并做资本配置”。  
- **[2022-02-26 via [[2026-05-15-buffett-2022-shareholder-letter]]]** 他强调自己和伯克希尔是“业务选择者”而非市场预测者，并以苹果、美国运通、可口可乐等长期持股样本说明这一点。  
- **[2021-02-28 via [[2026-05-15-buffett-2021-shareholder-letter]]]** 巴菲特把经营利润与 GAAP 收益严格区分，并把 PCC 110 亿美元减值直接认作自己 2016 年买贵了的错误，显示他对会计口径和资本配置失误都保持罕见的坦诚。  
- **[2024-02-24 via [[2026-05-15-buffett-2024-shareholder-letter]]]** 2024 年股东信对 [[charlie-munger|Charlie Munger]] 的角色有更高层次概括，反映巴菲特越来越倾向把伯克希尔讲成一套可传承的制度与资本配置文化，而不只是个人选股传奇。  

## 2015-2018 风格补充

- **[2015-02-28 via [[2026-05-15-buffett-2015-shareholder-letter]]]** 巴菲特在 2015 年就已经很清楚地区分账面价值与真实经济价值，说明他关注的重心始终不是报表表层数字，而是企业长期每股价值的变化。  
- **[2016-02-27 via [[2026-05-15-buffett-2016-shareholder-letter]]]** 2016 年他把 GEICO、BNSF 和生产力提升放在同一封信里讨论，显示其思路始终围绕“低成本优势 + 长期投入 + 复利机制”展开。  
- **[2017-02-25 via [[2026-05-15-buffett-2017-shareholder-letter]]]** 2017 年他把保险经营拆成一套明确纪律，也让外界更容易看见他不仅在做投资判断，更在搭建一整套组织化的风险与配置文化。  
- **[2018-02-24 via [[2026-05-15-buffett-2018-shareholder-letter]]]** 2018 年他提前提醒投资者不要被 GAAP 新规误导，反映出其一贯风格是主动拆解会计噪音，把注意力拉回经营现实和长期价值。  
- **[2016-02-27 via [[2026-05-15-buffett-2016-shareholder-letter]]]** 渲染后的正文说明，巴菲特会把估值判断直接落到行动上：当他认定账面价值低估内在价值时，就同步调整回购阈值，而不是只做概念讨论。  
- **[2017-02-25 via [[2026-05-15-buffett-2017-shareholder-letter]]]** 渲染后的 2017 正文把“承保纪律”和“回购价格纪律”放在同一封信里，显示他的风格本质上是统一的：不为错误价格买单。
