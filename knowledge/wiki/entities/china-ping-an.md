# 中国平安 / China Ping An

## 企业定位

[[china-ping-an|中国平安]] 是国内少数同时具备寿险、财险、银行、资管与金融科技布局的综合金融平台。放进 [[a-share-ten-core-stocks-202605]] 的横向框架里，它最值得重视的不是单一业务增速，而是“综合金融协同 + 寿险改革恢复 + 低估值 + 股息保护”这组组合。

## 2025 关键事实

- **[2026-05-15 via [[2026-05-15-ten-core-stocks-research-report]]]** 2025 年营业总收入约 10,505 亿元，同比增长 2.1%；归母净利润约 1,583 亿元，同比增长 7.9%。
- **[2026-05-15 via [[2026-05-15-ten-core-stocks-research-report]]]** 寿险新业务价值约 502 亿元，同比增长 39.8%，是这轮研究里最关键的经营改善信号之一。
- **[2026-05-15 via [[2026-05-15-ten-core-stocks-research-report]]]** ROE 约 13.97%，PE 约 7.5 倍，PB 约 0.99 倍，股息率约 4%，被报告列为“推荐”。
- **[2026-05-15 via [[2026-05-15-ten-core-stocks-research-report]]]** 财险综合成本率约 95.2%，平安银行不良率约 0.94%，显示核心金融资产质量仍具韧性。

## 护城河与回报结构

- 综合金融全牌照与交叉销售能力构成其主要 [[moat|护城河]]，这是多数单一保险公司或单一银行难以复制的能力组合。
- 寿险改革、新业务价值恢复与长期投资收益率改善，共同决定其 [[roe|ROE]] 能否继续维持在行业较优位置。
- 低于 1 倍的 PB 与稳定分红，使它同时具备一定 [[dividend|股息]] 防御性和估值修复弹性。

## 主要约束

- 宏观经济与利率下行会同时影响保险需求、净息差和投资收益。
- 业务结构复杂虽是优势来源，但也会带来长期估值折价。
- 投资端仍受资本市场波动影响，意味着它的低估值并不是无条件的“便宜”。

## 护城河模板卡片

按 [[moat-evaluation-template]] 这套母版看，中国平安当前可以被这样理解：

### 1. 护城河来源

- 综合金融全牌照；
- 交叉销售与客户协同；
- 客户与数据优势；
- 科技赋能与风控能力。

### 2. 财务体现

- [[roe|ROE]] 约 13.97%，对综合金融平台仍属较优；
- PB 约 0.99 倍，市场定价仍偏保守；
- 股息率约 4%，现金回报尚可；
- 财险综合成本率约 95.2%，平安银行不良率约 0.94%，说明资产质量与经营韧性仍有支撑。

### 3. 关键验证指标

- 寿险新业务价值增速；
- 财险综合成本率；
- 平安银行不良率；
- 集团综合投资收益率。

### 4. 失效信号

- 寿险改革红利明显回落；
- 财险成本率持续恶化；
- 资产质量走弱；
- 投资端波动长期吞噬经营改善。

### 5. 组合定位

- 核心跟踪层；
- 偏修复型质量资产；
- 更适合中长期跟踪，而不是短期博弈弹性。

### 6. 一句结论

它更像“综合金融护城河真实存在，但仍需持续用修复后的报表质量去验证”的公司。

## 当前观察

从 [[value-investing|价值投资]] 角度看，中国平安更像“质量仍可解释、但市场给了低估值”的修复型标的，而不是纯高增长故事。若后续继续跟踪，这家公司最值得盯住的不是短期股价，而是寿险新业务价值、财险成本率和集团资本回报率能否继续改善。
