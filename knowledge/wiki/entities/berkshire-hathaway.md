# 伯克希尔·哈撒韦 / Berkshire Hathaway

## 企业定位

[[berkshire-hathaway|伯克希尔·哈撒韦]] 是一家以保险业务为核心现金引擎、以长期 [[capital-allocation|资本配置]] 为治理中枢的多元控股集团。其商业模式并不依赖频繁交易，而是围绕控股企业、少数股权投资和再投资文化不断积累每股 [[intrinsic-value|内在价值]]。其长期方法论与沟通风格高度受 [[warren-buffett]] 主导，也因此经常被拿来作为 [[moat|护城河]]、[[buyback|回购]] 与长期复利框架的综合样本。

在当前知识库中，伯克希尔也是 [[value-investing|价值投资]] 从证券选择升级为企业经营、资金来源和配置纪律的核心案例。

## 2024-2025 关键事实

- **[2025-02-22 via [[2026-05-14-buffett-2025-shareholder-letter]]]** 2024 年营业利润为 474 亿美元。  
- **[2025-02-22 via [[2026-05-14-buffett-2025-shareholder-letter]]]** 2023 年向美国国税局缴纳企业所得税 268 亿美元，约占美国企业税收总额的 5%。  
- **[2025-02-22 via [[2026-05-14-buffett-2025-shareholder-letter]]]** 截至 2024 年末，少数股权投资组合市值约 2720 亿美元。  
- **[2025-02-22 via [[2026-05-14-buffett-2025-shareholder-letter]]]** 过去 20 年保险业务税后承保利润累计 320 亿美元，[[insurance-float|浮存金]] 从 460 亿美元增长到 1710 亿美元。  
- **[2025-02-22 via [[2026-05-14-buffett-2025-shareholder-letter]]]** 日本五大商社投资成本约 138 亿美元，市值约 235 亿美元。  

## 核心机制

1. 保险业务提供高质量 [[insurance-float|浮存金]]。  
2. 管理层将资金在控股并购、上市公司持股与现金储备之间进行纪律化配置。  
3. 极少分红、持续再投资，使资本留存在体系内滚动复利。  
4. 愿意坦诚承认错误并及时纠偏，降低配置失误的长期伤害。  

## 当前观察

这封最新股东信表明，伯克希尔的竞争优势依然不只是“低价买入”，更是把高质量资金来源、管理层纪律和长期持有文化结合起来。对研究者而言，它既是 [[capital-allocation|资本配置]] 的样板，也是 [[overview]] 中“长期主义 + 纪律 + 诚实披露”框架的现实案例。更完整的框架提炼见 [[buffett-2025-shareholder-letter-framework]]。

## 2020-2024 历年补充

- **[2024-02-24 via [[2026-05-15-buffett-2024-shareholder-letter]]]** 2023 年经营利润约 374 亿美元，且保险承保、保险投资收益、铁路、公用事业与能源等分部结构更清晰地展示了伯克希尔作为多元控股体系的经营面貌。  
- **[2024-02-24 via [[2026-05-15-buffett-2024-shareholder-letter]]]** Occidental 持股约 27.8%，日本五大商社成本约 1.6 万亿日元、市值约 2.9 万亿日元，显示其近年仍在用长期、可理解、现金流导向的方式配置资本。  
- **[2023-03-01 via [[2026-05-15-buffett-2023-shareholder-letter]]]** 在 Alleghany 帮助下，保险浮存金在 2022 年从 1470 亿美元增至 1640 亿美元；这意味着伯克希尔的资金质量不只是规模问题，更与承保能力和收购整合能力相关。  
- **[2022-02-26 via [[2026-05-15-buffett-2022-shareholder-letter]]]** 2021 年股东信把保险、苹果、BNSF、BHE 作为“四巨头”并列；同年末资产负债表上约有 1440 亿美元现金和现金等价物，其中约 1200 亿美元为一年内到期的美国国债，体现了伯克希尔始终保留极端时刻行动能力的纪律。  
- **[2021-02-28 via [[2026-05-15-buffett-2021-shareholder-letter]]]** 2020 年在没有大规模收购的情况下，伯克希尔仍通过留存收益和回购提高每股内在价值，说明它并不依赖单一大并购来维持复利。  
- **[2020-03-16 via [[2026-05-15-buffett-2020-shareholder-letter]]]** 2019 年 GAAP 净利润约 814 亿美元中，有约 537 亿美元来自未实现持仓收益；这说明研究伯克希尔时，必须把会计噪音与经营现实拆开看。  

## 2015-2018 历史补充

- **[2015-02-28 via [[2026-05-15-buffett-2015-shareholder-letter]]]** 巴菲特明确指出：随着伯克希尔越来越多地持有和经营大型企业，账面价值与真实商业价值之间的差距在不断扩大，这标志着公司已从证券组合型载体转向经营资产平台。  
- **[2016-02-27 via [[2026-05-15-buffett-2016-shareholder-letter]]]** GEICO 的成本优势、BNSF 的长期资本开支和通用再保险的优质 [[insurance-float|浮存金]]，共同说明伯克希尔的复利来源越来越依赖经营资产与低成本资金，而非账面数字好看。  
- **[2017-02-25 via [[2026-05-15-buffett-2017-shareholder-letter]]]** 2017 年股东信把保险经营的承保纪律说得更具体，也显示出伯克希尔已经具备更加制度化的资本配置能力，而不再只是巴菲特个人的投资集合。  
- **[2018-02-24 via [[2026-05-15-buffett-2018-shareholder-letter]]]** 2018 年 GAAP 新规开始把未实现股票波动系统性写进净利润，使伯克希尔的报表更容易偏离经营现实，这也是后续 [[gaap-vs-operating-earnings]] 变得更关键的背景。  
- **[2015-02-28 via [[2026-05-15-buffett-2015-shareholder-letter]]]** 本地浏览器渲染后的正文还显示：2015 年巴菲特已经把提升每股内在价值拆成五种典型动作，说明伯克希尔此时已具备成熟的配置操作框架。  
- **[2017-02-25 via [[2026-05-15-buffett-2017-shareholder-letter]]]** 渲染后的 2017 正文中，伯克希尔的浮存金已进入千亿美元级别，配合 Todd / Ted 的授权管理，公司的平台化特征比单纯“巴菲特选股”更明显。
