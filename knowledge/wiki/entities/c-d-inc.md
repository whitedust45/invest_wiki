# 建发股份 / C&D Inc.

## 企业定位

[[c-d-inc|建发股份]] 是这轮样本里最典型的“主业尚可、报表被拖累”的复杂案例。其供应链业务本身仍具规模与地位，但地产与美凯龙资产减值让公司短期从“低估值候选”变成了更需要辨认质量的标的，因此在 [[a-share-ten-core-stocks-202605]] 中被放入谨慎区。

## 2025 关键事实

- **[2026-05-15 via [[2026-05-15-ten-core-stocks-research-report]]]** 2025 年营业收入约 6,713 亿元，同比 -4.3%；归母净利润约 -108 亿元，同比大幅恶化。
- **[2026-05-15 via [[2026-05-15-ten-core-stocks-research-report]]]** 亏损主要来自美凯龙投资性房地产公允价值变动损失约 126 亿元及资产减值约 45-57 亿元。
- **[2026-05-15 via [[2026-05-15-ten-core-stocks-research-report]]]** ROE 约 -16.22%，PB 约 0.68 倍，报告评级为“谨慎”。
- **[2026-05-15 via [[2026-05-15-ten-core-stocks-research-report]]]** 供应链业务 2025H1 归母净利润约 14.2 亿元，海外业务规模约 140 亿美元，同比增长约 37%。

## 护城河与回报结构

- 国内大宗商品供应链龙头地位、综合服务能力和海外拓展能力，仍然构成它的主要 [[moat|护城河]]。
- 但这轮样本最重要的结论恰恰是：当地产和投资性资产减值足够大时，主业护城河并不能自动转化成好看的 [[roe|ROE]] 或清晰的估值逻辑。
- 分红政策延续对 [[dividend|股东回报]] 是正面信号，但当前不宜单独拔高。

## 主要约束

- 美凯龙减值和地产业务承压是压制估值修复的核心问题。
- 资产负债率较高，市场对风险出清时间缺乏确定感。
- 因为业务结构复杂，它更容易落入“看上去便宜，但很难快速判断便宜是否有效”的区域。

## 护城河模板卡片

按 [[moat-evaluation-template]] 这套母版看，建发股份当前可以被这样理解：

### 1. 护城河来源

- 供应链龙头地位；
- 综合服务能力；
- 海外拓展能力；
- 主业仍有一定规模与网络壁垒。

### 2. 财务体现

- PB 约 0.68，看起来很便宜；
- 但 [[roe|ROE]] 约 -16.22%，报表被大额减值严重扭曲；
- 供应链主业仍有盈利，但没有被整体报表干净地体现出来；
- 资产负债表和减值噪音是当前最大问题。

### 3. 关键验证指标

- 供应链主业利润；
- 美凯龙及地产业务减值进展；
- 海外业务增长质量；
- 资产负债率与现金流变化。

### 4. 失效信号

- 进一步大额减值；
- 负债继续抬升；
- 经营现金流恶化；
- 主业盈利也开始被侵蚀。

### 5. 组合定位

- 结构复杂观察层；
- 更适合风险识别和等待拐点，而不是提前高仓位表达。

### 6. 一句结论

它更像“主业也许不差，但报表与资产负债表暂时不足以证明其为高质量护城河公司”的案例。

## 当前观察

建发股份最值得沉淀为一个提醒样本：低 PB 不代表简单可买，先分清主业质量、资产减值和报表噪音，才谈 [[value-investing|价值投资]]。在这批素材里，它更像风险识别页，而不是核心优先配置页。
