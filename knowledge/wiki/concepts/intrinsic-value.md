# 内在价值 / Intrinsic Value

## 定义

[[intrinsic-value|内在价值]] 是资产或企业基于未来可分配现金流、资产质量和长期经济能力所对应的真实经济价值。它与市场交易价格不同，关注的是“值多少钱”，而不是“现在卖多少钱”。

## 为什么重要

- 投资的核心不是猜价格短期波动，而是判断价格与价值是否偏离。  
- 如果没有对内在价值的判断，[[margin-of-safety|安全边际]] 就无从谈起。  
- 对企业研究而言，内在价值能把注意力从短期情绪拉回到长期现金创造能力。  

## 与现有知识的关系

- [[margin-of-safety]] 是以 [[intrinsic-value|内在价值]] 为前提的防御机制。  
- [[capital-allocation|资本配置]] 的优劣，最终会反映在企业长期内在价值的变化上。  
- [[berkshire-hathaway]] 的长期实践说明，管理层更关心长期价值累积，而不是短期股价好看。  
- 在方法上，它常与 [[dcf-model|DCF]]、[[fcf|自由现金流]]、[[gaap-vs-operating-earnings|GAAP 与经营利润]]、[[value-investing|价值投资]]、[[moat|护城河]]、[[roe|ROE]]、[[buyback|回购]] 和 [[confirmation-bias|确认偏误]] 一起出现：前几者帮助估值，最后一个提醒我们别把乐观故事错当成价值判断。  

## 当前知识库中的用法

作为基础估值概念，这一页的作用是给后续 DCF 模型、[[margin-of-safety]] 与企业分析页提供共同锚点。它不预设唯一估值方法，但要求后续讨论始终区分“价值判断”和“价格观察”。

## 静态清算价值视角

[[static-value-cigar-butt-framework|静态价值型烟蒂投资框架]] 把 [[intrinsic-value|内在价值]] 的一部分压缩到当前资产负债表：如果公司可变现资产扣除真实负债后的 [[asset-cushion|存量资产垫]] 已经高于市值，那么即使未来增长很弱，也可能存在资产型低估。

但这只是内在价值的一种保守下限视角。它不能替代对资产可变现性、负债真实性、治理结构和 [[positive-cash-inflow|正现金流入]] 的检查；否则“静态清算价值”容易被错误资产、隐藏负债或持续烧钱侵蚀。

## 与当前素材的连接

**[2025-02-22 via [[2026-05-14-buffett-2025-shareholder-letter]]]**  
巴菲特在 2025 股东信中虽然没有系统展开“内在价值”术语，但他反复强调：优质企业股权优于长期持有现金与固定利息资产，资本应持续流向长期最优去处。这种思路的底层前提正是：企业存在独立于短期市场价格的长期经济价值。

**[2015-02-28 via [[2026-05-15-buffett-2015-shareholder-letter]]]**  
2015 股东信明确指出：随着伯克希尔越来越多地持有和经营大型企业，账面价值与 [[intrinsic-value|内在价值]] 的差距会不断拉大，这说明真实价值必须回到经营资产与长期盈利能力来理解。

**[2018-02-24 via [[2026-05-15-buffett-2018-shareholder-letter]]]**  
2018 股东信进一步补充了“look-through”视角：即使会计上只确认了股息和短期资本利得，被投企业留存利润依然可能在持续增加长期内在价值。

**[2016-02-27 via [[2026-05-15-buffett-2016-shareholder-letter]]]**  
渲染后的 2016 正文提供了一个更操作化的例子：巴菲特把回购阈值提高到账面价值的 120%，正是因为他认为账面价值越来越低估真实的 [[intrinsic-value|内在价值]]。

**[2018-02-24 via [[2026-05-15-buffett-2018-shareholder-letter]]]**  
同一封渲染后的 2018 正文还把“市场短期是投票器、长期是称重机”与伯克希尔历史上的多次大回撤放在一起，说明短期股价波动并不自动等于内在价值受损。

**[2023-03-01 via [[2026-05-15-buffett-2023-shareholder-letter]]]**  
渲染后的 2023 正文用可口可乐和美国运通给出更直观的长期样本：两笔都约 13 亿美元成本的投资，到 2022 年分别对应约 250 亿 / 220 亿美元市值和持续上升的股息流，说明少数真正优秀的商业模式会在很长时间里不断放大 [[intrinsic-value|内在价值]]。

**[2026-06-18 via [[2026-06-18-berkshire-official-shareholder-letter-archive]]]**  
官方历史材料进一步把内在价值拆成几个可观察来源：1983 年的经济商誉说明高回报生意为什么能高于净有形资产价值；1992 和 2019 年的 look-through / retained earnings 视角说明被投企业留存利润会继续推升长期价值；1996 年信则明确把市场价格与内在价值的关系作为股东公平性的核心问题。
