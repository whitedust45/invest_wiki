# 价值投资 / Value Investing

## 定义

[[value-investing|价值投资]] 是一种先估算 [[intrinsic-value|内在价值]]、再在价格明显低于价值时买入的投资方法。它不是单纯寻找“便宜股票”，而是寻找“价格低于价值”的资产，并通过 [[margin-of-safety|安全边际]] 为判断误差、周期波动和市场情绪预留缓冲。

## 核心构件

1. **内在价值**：先判断企业大致值多少钱，而不是先看股价涨跌。  
2. **安全边际**：买入价要明显低于估算价值，给错误留余地。  
3. **基本面研究**：重点看盈利能力、现金流、资产质量、负债、竞争优势和管理层。  
4. **长期持有**：价值实现经常需要时间，短期价格并不总能立即反映基本面。  
5. **逆向纪律**：当市场因恐慌或叙事失真而错价时，才更可能出现机会。  

**[2026-06-18 via [[2026-06-18-berkshire-official-shareholder-letter-archive]]]**  
Berkshire 官方历史股东信把这套框架补得更完整：1983 年的经济商誉解释“好生意”为什么重要，1986 年的 [[fcf|所有者收益]] 解释为什么不能只看 GAAP 利润，1984 年的 [[buyback|回购]] 纪律说明价格必须低于 [[intrinsic-value|内在价值]]，1990 年代的 [[insurance-float|浮存金]] 框架说明低成本资金必须以承保纪律为前提。这些材料共同说明，[[value-investing|价值投资]] 是“好生意 + 真实现金收益 + 价格纪律 + 资本配置”的组合，而不是单纯低估值筛选。

在成熟企业语境里，[[dividend|股息]] 也可能是价值实现的一部分，但前提仍然是分红建立在真实自由现金流与合理资本配置之上，而不是把缺乏再投资机会误读成质量优势。

## 格雷厄姆式烟蒂路径

[[cigar-butt-investing|烟蒂投资]] 是 [[value-investing|价值投资]] 中更偏静态资产折价的一支。它不要求公司长期伟大，而要求当前市场价格显著低于可确认资产价值，并且这层折价不会被后续经营持续消耗。

在当前知识库里，这一路径由 [[static-value-cigar-butt-framework|静态价值型烟蒂投资框架]] 承接。其核心不是低 PE 或低 PB，而是先验证 [[asset-cushion|存量资产垫]]，再验证 [[positive-cash-inflow|正现金流入]]，最后等待资产兑现逻辑。它与芒格-巴菲特式“合理价买优秀企业”不同，更接近格雷厄姆式“用清算价值保护本金”的方法。

## 芒格-巴菲特版本的升级

经典格雷厄姆式价值投资更强调“折价”；而 [[charlie-munger|芒格]] 与 [[warren-buffett]] 把它升级为“折价 + 企业质量 + 长期复利”。

- **[2023-03-01 via [[2026-05-15-buffett-2023-shareholder-letter]]]** 巴菲特说“我们不是选股高手，我们是选择商业模式的人”，说明价值投资不应停留在估值表面，而要深入到生意本身。  
- **[2025-02-22 via [[2026-05-14-buffett-2025-shareholder-letter]]]** 巴菲特回顾伯克希尔纺织业务时承认：买得便宜不够，坏生意会吞噬折价。  
- **[2025-07-14 via [[2026-05-15-investopedia-value-investing]]]** Investopedia 也把价值投资定义为“低于内在价值买入”，但同时强调竞争优势、现金流、品牌和商业模式都属于估值的一部分。  

## 与成长、动量、逆向的区别

- 与 [[growth-investing|成长投资]] 相比，价值投资更强调“价格是否留有余地”；成长投资则更愿意为未来增长支付溢价。  
- 与 [[momentum|动量]] 策略相比，价值投资并不把价格上涨本身当作买入理由，而更关注价格是否偏离价值。  
- 与 [[contrarian|逆向投资]] 相比，价值投资常常带有逆向特征，但逆向只是行为方向，价值才是判断锚点；与 [[mean-reversion|均值回归]] 相比，它也更依赖基本面而非统计偏离。  

## 常见误解

- **误解一：价值投资就是买低价股。** 关键不是股价绝对便宜，而是相对价值被低估。  
- **误解二：只看 PE/PB 就够了。** 单一倍数无法替代对商业模式、现金流和资本配置的完整分析。  
- **误解三：价值投资不看未来。** 恰恰相反，[[intrinsic-value|内在价值]] 本身就依赖对未来现金流与竞争地位的判断。  
- **误解四：价值投资天然低风险。** 若估错价值、忽视基本面恶化、或把坏生意误认成便宜货，同样会遭受永久性损失。  
- **误解五：只要故事足够动人就算看懂了价值。** 真正的 [[value-investing|价值投资]] 必须持续对抗 [[narrative-fallacy|叙事谬误]]。  

## 与现有知识的关系

- [[value-investing|价值投资]] 的估值锚点见 [[intrinsic-value]]；在规则化投资语境下，它也可以被抽象为 [[factor-investing|价值因子]]。  
- 它的防御机制见 [[margin-of-safety]]。  
- 它在企业质量层面的升级，必须连接 [[moat|护城河]] 与 [[charlie-munger]]。  
- 它与 [[kelly-criterion|凯利公式]] 的关系是上下游：前者回答“为什么可能有优势”，后者回答“既然有优势该下多大”。  
- 在伯克希尔语境下，它最终会落实为 [[capital-allocation|资本配置]]：把资本从坏生意移开，转向能长期复利的优质资产。
