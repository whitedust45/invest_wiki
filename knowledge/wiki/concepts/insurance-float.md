# 保险浮存金 / Insurance Float

## 定义

[[insurance-float|保险浮存金]] 是保险公司在赔付尚未发生前已收取的保费所形成的可投资资金。它并不是“免费钱”，只有在承保利润不为负、赔付估计合理、长尾风险受控时，才可能接近低成本甚至无成本资金。

在 [[value-investing|价值投资]] 语境下，浮存金的意义不只是融资便宜，而是它能否以低成本支持长期资本配置，同时不引入会毁掉复利的尾部负债。

## 为什么重要

- 浮存金让保险公司能够在支出发生前先获得现金。  
- 如果承保质量高，浮存金相当于为投资组合提供了稳定、低成本的资金来源。  
- 如果承保定价不足或管理层过于乐观，浮存金会掩盖真实亏损，最终放大风险。  

## 伯克希尔案例

**[2025-02-22 via [[2026-05-14-buffett-2025-shareholder-letter]]]**  
巴菲特将财产与意外保险视为 [[berkshire-hathaway]] 的核心业务之一。过去 20 年，伯克希尔保险业务税后承保利润累计 320 亿美元，浮存金从 460 亿美元增至 1710 亿美元；这说明浮存金的质量，不仅来自规模，更来自承保纪律、风险定价和对极端损失的承受能力。

## 使用提醒

- 研究保险公司时，不能只看浮存金规模，还要看 combined ratio、长尾负债和准备金质量。  
- 浮存金本质上是 [[capital-allocation|资本配置]] 问题的一部分：融资成本越低，可配置资产的长期复利空间越大。  
- 当自然灾害频率和赔付不确定性上升时，浮存金质量会比数量更重要。  

## 历年演进补充

- **[2021-02-28 via [[2026-05-15-buffett-2021-shareholder-letter]]]** 2020 年时，伯克希尔持有的保险浮存金约为 1380 亿美元。  
- **[2022-02-26 via [[2026-05-15-buffett-2022-shareholder-letter]]]** 到 2021 年，这一数字约增长到 1470 亿美元。  
- **[2023-03-01 via [[2026-05-15-buffett-2023-shareholder-letter]]]** 2022 年在 Alleghany 带动下进一步增加到 1640 亿美元；渲染后的正文还补充说明，只有在严格承保下，这些资金才有相当大机会接近零成本。  
- **[2025-02-22 via [[2026-05-14-buffett-2025-shareholder-letter]]]** 再往更长周期看，过去 20 年浮存金从 460 亿美元增长到 1710 亿美元，说明长期价值来自承保纪律、风险定价与配置能力的共同积累。  

## 2016-2017 结构补充

- **[2016-02-27 via [[2026-05-15-buffett-2016-shareholder-letter]]]** 巴菲特在 2016 年用 GEICO 和通用再保险的历史说明：好的 [[insurance-float|浮存金]] 并不只是规模扩张，而是能在长期里接近零成本甚至优于零成本。  
- **[2017-02-25 via [[2026-05-15-buffett-2017-shareholder-letter]]]** 2017 年他把承保纪律拆成四条标准，进一步说明浮存金质量首先是承保文化问题，其次才是报表上的资金数字。  
- **[2015-02-28 via [[2026-05-15-buffett-2015-shareholder-letter]]]** 本地浏览器渲染后的 2015 正文给出更具体的历史轮廓：过去 12 年浮存金从约 410 亿美元增长到 840 亿美元，同时累计承保盈利约 240 亿美元。  
- **[2016-02-27 via [[2026-05-15-buffett-2016-shareholder-letter]]]** 渲染后的 2016 正文把这条曲线继续往前推到 880 亿美元，并把 13 年累计承保盈利写到约 260 亿美元。  
- **[2017-02-25 via [[2026-05-15-buffett-2017-shareholder-letter]]]** 渲染后的 2017 正文显示伯克希尔通过大额再保险合同进入千亿美元级别浮存金平台，说明规模扩张与承保纪律可以同步发生。  

## 1990 年代官方框架补充

**[1995-1996 via [[2026-06-18-berkshire-official-shareholder-letter-archive]]]**  
1995 和 1996 年官方股东信把浮存金拆成三个问题：规模、成本、长期前景。浮存金是“持有但不拥有”的资金；如果承保成本长期低于可替代资金成本，它就是优势；如果承保亏损超过市场资金成本，它就会变成负担。这比“浮存金越多越好”更严格，也更适合作为分析保险公司的基础框架。
