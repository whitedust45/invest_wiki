# 龟龟选股因子1：商业模式截图摘录

> 来源说明：本页只引用用户提供的本地截图素材，路径为 `knowledge/raw/assets/guigu-investing-method/stock-factor-01-business-model/`。截图可见 B 站标题和 UP 主水印，但未提供可核验 URL。

## 核心摘要

商业模式被定义为“企业产生利润的方式”，是选股最核心的因子。龟龟框架把它拆成六个问题：能否看懂、是否需要重复性资本开支、赚的是真钱还是假钱、竞争还是垄断、有没有定价权、周期性有多强。

## 逐图摘录

| 图片 | 画面主题 | 关键内容 |
|---|---|---|
| 00 | 因子定位 | 用高息股替代 ETF 的目标，是筛出一套寻觅股息穿透稳定的企业，适合有研究热情且有一定毅力的投资者。精选高息个股用于替代被动型红利 ETF。 |
| 01 | 商业模式六问 | 商业模式是公司是否为“好生意”的根源，关注利润稳定性、可支配比率、提价权、重复资本开支等。六问包括：能否看懂、重复性资本开支、真/假钱、竞争/垄断、定价权、周期性。 |
| 02 | 能否看懂 | 第一步是看懂公司经营和主要产品。若看不懂产品、生意内容或知识水平不足以理解，即使别人赚了钱，也不应买入，否则是在投机。 |
| 03 | 看懂的一票否决例子 | 康方生物的创新药管线、治疗方向和消费场景对普通投资者很难理解；伊利股份的主要产品清晰可理解。看不懂时，收息目的投资应直接否决。 |
| 04 | 康方案例材料 | 截图展示康方生物报告中大量新药、适应症、临床管线和商业化表述，用作“普通人难以理解复杂医药商业模式”的例子。 |
| 05 | 伊利案例材料 | 伊利报告展示 2024 年收入 1157.80 亿、净利润 84.64 亿，液体乳收入 750.03 亿，并列举金典、舒化、安慕希等产品线，用作更容易理解的消费品生意例子。 |
| 06 | 重复性资本开支 | 能看懂商业模式后，要看公司利润是否依赖持续且重复的大额资本开支。理想生意是在前期重大资本开支落地后，后续只需低成本开支即可产生更高比例自由现金流。 |
| 07 | 殡葬 vs 商品房 | 商品房需要反复拿地、建房、销售，再继续拿地；墓园则前期建园后单个墓园平均销售 30-60 年，后续主要是工资成本，长期毛利率可接近 80% 以上。 |
| 08 | 资本开支曲线 | 用收入/成本曲线说明，重复性资本开支企业在经济衰退期可能亏损；递减型资本开支企业可依靠旧利润和低后续开支释放现金。 |
| 09 | 真钱还是假钱 | 真钱指收现金，假钱指应收账款。先钱后货的模式风险较低；先货后钱甚至长期垫资供货的模式，存在坏账、资金占用和财务费用风险。 |
| 10 | 应收账款分叉 | 博彩业通常先收钱再服务，几乎没有应收账款；电力公司可能赚了利润却都是应收账款，不敢催收，导致赚了钱却无钱运营，需要贷款度日。 |
| 11 | 现金/应收对比 | 截图对比银河娱乐和华润电力的现金与应收结构，强调应收账款为主的企业商业模式较差，真正赚现金的企业商业模式更优。 |
| 12 | 垄断还是竞争 | 垄断可以来自激烈竞争中的领先，也可以来自国家资质保护。竞争型行业难以判断趋势，且容易整体亏损；垄断型行业通常利润和现金流更稳定，但可能承担社会责任。 |
| 13 | 资质垄断图示 | 国家/地方授予电信、国有银行、澳门博彩等特许经营资质，使其在垄断市场中分享利润；普通股份制企业则面向市场竞争，可能激烈竞争盈利或赢家通吃。 |
| 14 | 定价权定义 | 定价权指企业主动调整产品售价的能力，不等于价格一定变化，而强调主动性。定价权强的企业可把成本上涨传导给下游，抵御毛利率大幅波动。 |
| 15 | 定价权例子 | 发电企业售电价受政府主导，煤价大涨时无法传导成本，2021-2022 年曾出现发一度电亏几分钱；双汇可通过调整火腿肠价格，在猪周期中维持利润和股息。 |
| 16 | 定价权财务例子 | 截图对比华能国际和双汇发展净利润，华能 2021/2022 年出现亏损，双汇利润相对稳定。 |
| 17 | 定价权曲线 | 有定价权企业可在成本上涨阶段逐步转移成本；无定价权企业在成本越过售价后陷入亏损。图中解释火电被煤价拖入亏损，猪肉价格波动时双汇可调价维持利润。 |
| 18 | 周期性定义 | 周期性同时指成本侧和产品售价侧。产品高度一致会让企业处于博弈环境：盈利时扩产，产能过剩后亏损，随后退产，直到周期回升。煤炭、石油、金属是强周期例子。 |
| 19 | 强周期图示 | 顺周期意味着利润不稳定，股息回报不可预测。截图用锂矿行业示意供需错配、景气期、内卷低谷和再景气。 |
| 20 | 弱周期图示 | 弱周期行业供需波动小，利润更稳定，收息回报更稳定。图中展示需求与供给围绕长期趋势小幅波动。 |
| 21 | 理想商业模式条件 | 最佳商业模式包括：能充分理解行业和企业；较低重复性资本开支；以现金为主的收款模式；具备一定垄断性；具备定价权；市场周期性较弱，未来利润和股息预测性更强。 |

## 可沉淀判断

- 本组材料可直接强化 [[moat-evaluation-template]]：护城河不仅要讲来源，还要追问现金回收、重复资本开支、定价权和周期性。
- 对高股息公司而言，“看得懂 + 低重复资本开支 + 真现金 + 弱周期”比单纯高股息率更重要。
- 这套商业模式筛选不是为了寻找最高成长，而是为了降低未来股息和现金流预测误差。
