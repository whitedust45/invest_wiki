# 龟龟仓位管理1：弹性差与商业模式仓位截图摘录

> 来源说明：本页只引用用户提供的本地截图素材，路径为 `knowledge/raw/assets/guigu-investing-method/position-management-01-elasticity-gap-business-model-position-limits/`。截图可见 B 站标题和 UP 主水印，但未提供可核验 URL。

## 核心摘要

这组截图提出四条仓位原则：市场位置决定组合弹性，个股商业模式决定仓位上限，具体价格决定实际仓位，对同一类型风险敞口要合并限制。它适合长期个股投资者，不适合短线交易者。

## 逐图摘录

| 图片 | 画面主题 | 关键内容 |
|---|---|---|
| 00 | 仓位管理总览 | 仓位管理仅适合个股投资者；被动 ETF 可按指数综合值调整。核心要义：市场位置决定持仓综合弹性，个股商业模式决定个股仓位上限，个股具体价格决定实际仓位，同类型风险敞口要合并限制。 |
| 01 | 原则1：市场位置决定弹性 | 市场长期存在均值回归，不是长期单边走势。偏离均值时存在弹性套利空间：市场高于长期均值时降低整体波动率，市场低于长期均值时提高组合弹性，从均值回归中获得“弹性差”。更强的市场位置判断可观察整个市场绝对回报率，如成熟权重股股息率/穿透回报率下降意味着市场位置偏高。 |
| 02 | 原则1实践 | 低位时买成长股或高波动股票，如恒指低于 1.7 万点时大量买药明生物、腾讯、百胜中国；高位时转入公共事业或低波动股票，如恒指高于 2.1 万点时转入长实、长和等。 |
| 03 | 弹性差例子 | 公司波动率差异决定弹性：药明生物、腾讯等近三年平均波动率大于 40%，长和、长实、福寿园等约 10% 或更低。恒指从 1.7 万回归到 2 万，高弹性扩大收益；从 2.2 万以上回归到 2 万，低弹性减少损失。 |
| 04 | 原则2：商业模式决定上限 | 越好的商业模式，利润变量越少、稳定性越强，可判断性和延续性越清楚，因此可以承载更高仓位。风险主要是无法预测、无法判断的基本面变化，而不是股价短期未反映利好。越判断不清的资产，越要限制仓位。 |
| 05 | 商业模式上限例子 | 近两年仓位大于 20% 的老朋友包括腾讯、百胜中国、福寿园、长和、长实等；低于 20% 的包括龙湖、理文造纸、裕元集团等。高仓位核心原因是商业模式更稳定，例如腾讯社交近乎垄断、百胜中国品牌矩阵、福寿园殡葬资源稀缺、长和公共事业和出租现金流稳定。低仓位多因商业模式缺陷，如周期、负债、衰退或关税风险。 |
| 06 | 原则3：价格决定实际仓位 | 商业模式决定上限，不代表一定推升到上限。实际仓位取决于价格是否足够低。推升超过 20% 仓位的点通常是接近 5 年最低股价，且穿透回报率达到约 7% 以上。例子包括 220 港元百胜中国穿透回报率接近 10%，200 多港元腾讯回购加股息超过 6.5%，两长成本也超过 6%。若绝对回报率无法达到 6% 以上，即使商业模式好，也不应推升过多仓位。 |
| 07 | 原则4：同源风险合并 | 同类风险敞口要合并限制，本质是提高分散度，避免黑天鹅对组合集中打击。若持有地产行业仓位已经超过 40%，应主动放弃更多地产因子；例如长实 + 龙湖已有 30% 仓位时，可能不再考虑绿城等同源地产敞口。 |
| 08 | 弹性补充 | 市场位置较高时要降低弹性，通常顺序是从高波动率股票慢慢切换到优质低波动率公司；若找不到足够优质的低波动股票，或标的本身波动率已够低，则考虑固收或现金等价物。实际顺序可概括为：高波动率 -> 低波动率个股 -> 降低整体仓位。 |

## 可沉淀判断

- 龟龟仓位管理不是只看单股好坏，而是把市场位置、股票弹性、商业模式质量、价格和相关风险统一起来。
- 这套规则能补强 [[personal-position-sizing-framework]]：原有框架强调凯利、安全边际和回撤，龟龟补上“在不同市场位置如何调组合弹性”的执行层。
- “好公司也要看价格，价格够低才推升仓位”与 [[margin-of-safety]] 和 [[tiered-position-sizing-template]] 高度一致。
