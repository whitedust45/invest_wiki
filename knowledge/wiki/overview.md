# 投资理念全局概览

_本页是整个投资知识库的顶层入口，随着素材摄入和思考深入会持续演进。_

## 核心投资原则

**[2026-05-14 via [[2026-05-14-buffett-2025-shareholder-letter]]]**

1. 资本配置错误不可避免，但必须尽快承认并纠正，不能拖延。  
2. 长期复利依赖于把留存收益持续投入高回报资产，而不是机械偏好 [[dividend|分红]]。  
3. [[insurance-float|保险浮存金]] 只有在承保纪律严格时，才是真正优质的资金来源。  
4. 会计口径经常会放大噪音，研究复杂企业时要优先区分经营现实与报表表象。  
5. [[buyback|回购]] 只有在价格低于内在价值时才是股东友好的配置动作。  
6. [[charlie-munger|芒格]] 式修正提醒我：便宜不是终点，真正重要的是好生意、好管理层与可持续复利。  

## 方法论框架

- **总纲**：[[value-investing|价值投资]] 作为总框架，把价格、价值、企业质量与时间统一起来。
- **估值方法**：[[intrinsic-value|内在价值]]、[[dcf-model|DCF]] 与倍数法结合使用，而不是只看单一指标。
- **选股标准**：[[moat|护城河]]、[[roe|ROE]]、管理层、资本再投资能力与纠错文化。
- **买卖纪律**：以 [[margin-of-safety|安全边际]] 约束买入，以 thesis 失效和纠错速度约束卖出，而不是把价格波动本身当成唯一信号。
- **组合管理**：[[asset-allocation|资产配置]] 定骨架，[[diversification|分散化]] 铺风险来源，[[rebalance|再平衡]] 维护纪律，[[position-sizing|仓位]] 决定单笔深度，并用 [[risk-reward|风险收益比]] 评估单笔机会是否值得下注。
- **资本配置**：控股业务、上市股权、现金与融资工具之间如何分配？见 [[capital-allocation]]

### [2026-05-18 补充] 风险—仓位—复利这条执行主线

这轮关于 [[kelly-criterion|凯利公式]] 的讨论，让组合执行层的入口可以更明确地拆成三页：

- [[kelly-criterion]]：回答“如果 edge 为正，该下多大”，重点在 edge、对数增长与分数凯利。  
- [[drawdown]]：回答“为什么深回撤不只是难熬，而且会伤害复利效率”。  
- [[position-sizing]]：回答“这些理论最终如何落实为组合中的实际权重控制”。  

如果以后从全局概览进入风险管理体系，我会优先按 `凯利公式 → 回撤 → 仓位管理` 这条顺序阅读；它对应的是“先理解公式目标，再理解回撤代价，最后理解执行表达”。  

### [2026-05-21 / 2026-05-22 补充] Taleb 的肥尾—反脆弱—凸性—杠铃主线

除了上面的“风险—仓位—复利”执行主线，这次 raw 还让我把另一条线补得更清楚：

- [[antifragile]]：回答“在一个肥尾世界里，什么样的系统会因为波动和混乱而受益？”  
- [[convexity]]：回答“这种受益的数学与收益结构机制到底是什么？”  
- [[barbell-strategy]]：回答“如果要把这种世界观落到组合结构上，最典型的表达是什么？”  
- [[drawdown]]：回答“为什么这种结构真正想规避的不是普通波动，而是一次性伤筋动骨的极端回撤？”  

如果以后从塔勒布方法论进入，我会优先按 `反脆弱 → 凸性 → 杠铃策略 → 回撤` 这条顺序阅读；它对应的是“先理解世界观，再理解机制，再理解组合结构，最后理解它真正想解决的风险”。  

### [2026-06-18 补充] 巴菲特官方股东信的核心价投主线

这轮补充把更早年份的 Berkshire 官方材料接进知识库，形成一条更完整的基础路径：

- [[moat]]：从 1983 年“经济商誉/特许经营权”理解好生意为什么能长期高回报。  
- [[fcf]]：从 1986 年“所有者收益”理解为什么估值不能只看 GAAP 利润。  
- [[buyback]]：从 1984 年“低于内在价值才回购”理解股东回报的价格纪律。  
- [[insurance-float]]：从 1995-1996 年材料理解浮存金的规模、成本和长期前景。  
- [[capital-allocation]]：把留存收益、并购、回购、现金储备和被投企业再投资统一到每股内在价值增长。  

以后从巴菲特线进入，我会优先按 `经济商誉 → 所有者收益 → 内在价值 → 安全边际 → 资本配置` 这条顺序阅读。完整提炼见 [[buffett-shareholder-letters-core-value-investing]]，原始素材池见 [[2026-06-18-berkshire-official-shareholder-letter-archive]]。

## 能力圈

- 巴菲特—伯克希尔方法论：重点理解 [[capital-allocation]]、[[insurance-float]]、[[gaap-vs-operating-earnings]] 与 [[charlie-munger]] 的共同作用。  
- 价值投资框架：重点区分 [[value-investing]]、[[growth-investing]]、[[momentum]]、[[contrarian]] 与 [[mean-reversion]] 的判断锚点差异。  
- 因子框架：重点理解 [[factor-investing]] 如何把价值、[[momentum|动量]] 与 [[carry|Carry]] 等收益来源规则化。  
- 组合执行纪律：重点连接 [[asset-allocation]]、[[diversification]]、[[rebalance]]、[[position-sizing]]、[[kelly-criterion]] 与 [[dollar-cost-averaging]]。  
- Taleb 风险观：重点连接 [[antifragile]]、[[convexity]]、[[barbell-strategy]]、[[drawdown]]，理解肥尾世界中的生存性设计。  

其中，若要真正把“组合执行纪律”读透，最关键的不是只知道这些词，而是顺着一条链路去看：  

1. [[kelly-criterion]] 提供仓位的公式化语言；  
2. [[drawdown]] 解释仓位过大为何会非线性伤害资金曲线；  
3. [[position-sizing]] 再把这些约束落到实际的权重与上限表达。

## 开放问题

1. 当“好生意”与“足够便宜”不能同时满足时，应优先坚持质量还是价格纪律？  
2. 对个人长期账户而言，[[dollar-cost-averaging]] 与 [[rebalance]] 的结合边界应如何设计，才能既保持纪律又不过度交易？  
3. 在什么条件下，[[mean-reversion]] 的统计偏离能真正转化为可执行机会，而不是逆势接飞刀？  
4. 组合层面如何把 [[fcf|自由现金流]] 质量、[[drawdown|回撤]] 承受力与 [[narrative-fallacy|叙事谬误]] 风险同时纳入判断？
