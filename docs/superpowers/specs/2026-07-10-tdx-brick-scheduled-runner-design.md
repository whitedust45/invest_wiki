# 通达信砖型图定时运行器设计

## 目标

在 Windows 当前登录用户会话内，于每个工作日 14:40 自动执行砖型图筛选。任务负责启动或复用通达信客户端，等待 TQ 接口就绪后调用现有 `tools/dashboard/tdx_brick_selector.py`，并保留可追溯的结果与日志。

## 已确认约束

- 触发日：周一至周五；不额外接入交易日历。
- 触发时间：14:40。
- 未启动通达信时，自动启动 `F:\new_tdx64\TdxW.exe`。
- 就绪检测：每 30 秒一次，执行窗口截止于 14:55。
- 超过 14:55、未登录、TQ 未就绪、行情缺失或公式结果无法识别时，当天失败且不补跑。
- 任务仅在用户登录时运行；不尝试在非交互会话运行 GUI 通达信。
- 不关闭已启动或用户正在使用的通达信客户端。
- 自动运行采用 `--engine both`，概念板块数量维持 5，原生公式名维持 `砖`。
- 结果写入 `data/tdx-brick-selector/runs/YYYY-MM-DD.json`；过程日志写入 `data/tdx-brick-selector/logs/YYYY-MM-DD.log`。同一天后一次运行覆盖同名文件。
- 创建任务后不推送远程仓库。

## 方案选择

采用“Windows 任务计划程序 + PowerShell 运行器”。任务计划程序负责可靠地跨重启保留触发规则；PowerShell 运行器负责 GUI 客户端启动、TQ 就绪重试、执行 Python、输出落盘与退出码。

不采用常驻 Python 调度进程，因为其在 Windows 重启或终端关闭后需要额外守护恢复。也不让任务计划程序直接调用 Python 筛选器，因为现有脚本不承担客户端启动和 14:55 截止控制。

## 组件

### `tools/dashboard/run_tdx_brick_selector.ps1`

Windows 运行器，参数包括项目目录、通达信根目录、通达信可执行文件、Python 命令、开始时间、截止时间、轮询秒数和输出根目录。

运行器步骤：

1. 计算当日结果与日志路径并创建目录。
2. 检测 `TdxW.exe` 是否运行；未运行则启动 `F:\new_tdx64\TdxW.exe`。
3. 从 14:40 起每 30 秒调用 Python 筛选器的轻量 TQ 预检；预检成功即进入正式筛选。
4. 到 14:55 仍未就绪则写失败日志并返回非零退出码。
5. 正式调用 `tdx_brick_selector.py --engine both --json --output <当日结果路径>`；将标准输出和标准错误追加到当日日志。
6. 保留 Python 退出码，不伪造成功。

预检仅验证 TQ 模块、客户端连接和概念板块数据可读；不运行原生公式，不创建候选结果。

### `tools/dashboard/install_tdx_brick_selector_task.ps1`

一次性安装器。默认以当前登录用户创建任务 `TDX Brick Selector 14:40`，使用 Windows PowerShell 调用运行器，设置为：

- 周一至周五 14:40；
- 只在用户登录时运行；
- 不在错过计划后补跑；
- 不因空闲/电源状态阻止启动；
- 已有同名任务时先更新，不创建重复任务。

安装器自动优先发现 `py -3`，其次 `python`；也允许显式传入 Python 可执行命令。项目根目录从安装器所在路径计算，不依赖固定的 `F:\invest_wiki\invest_wiki` 路径。

### 现有 Python 筛选器

不改变交易信号规则。继续拒绝非有限行情值、陈旧日线和未明确返回 `XG` 的原生公式结果。运行器将这些错误写入日志与 JSON 结果，不将其转换为候选。

## 失败处理

| 场景 | 行为 |
| --- | --- |
| `TdxW.exe` 不存在或启动失败 | 写日志，退出失败 |
| 14:55 前 TQ 未就绪 | 写日志，退出失败，不补跑 |
| 通达信返回缺失/NaN 日线 | Python 结果记录逐股错误，不产生假信号 |
| 原生返回未包含 `XG` | 原生批次记录错误，不产生原生命中 |
| 周末或停市 | 当前日线校验失败，写日志，不产生候选 |
| 任务重复触发 | Windows 任务配置为忽略新的并发实例 |

## 验收标准

1. PowerShell 运行器可在 Windows 手工调用，并在不存在通达信进程时启动 `TdxW.exe`。
2. 未就绪时最多等待至 14:55，期间每 30 秒记录一次尝试。
3. 安装器可创建或更新当前用户任务；再次运行不生成重复任务。
4. 当日 JSON 与日志均按约定路径生成；日志包含启动、等待、正式执行、退出码和失败原因。
5. Python 的现有单元测试继续通过；PowerShell 脚本以静态结构测试覆盖关键路径与任务设置。

## 非目标

- 不自动下载全 A 股盘后数据。
- 不自动登录需要人工验证码或密码的通达信账户。
- 不发送消息通知，不下单，不写 SQLite，不补跑错过的尾盘任务。
